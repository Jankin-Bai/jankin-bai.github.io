## 开篇：一个电路里有3个电源、5个节点、8个元件，怎么算？

前面几篇我们学了串联、并联、串并联的分析方法。但实际电路往往更复杂——比如一个运算放大器电路，有正电源、负电源、信号源，还有反馈网络；再比如一个电源电路，有整流桥、滤波电容、稳压芯片、负载。这种多电源、多节点的复杂电路，用串并联化简的方法根本搞不定。

怎么办？答案是用**系统化的分析方法**。这篇文章我们就把复杂AC电路的"解题工具箱"彻底讲透：电源转换、叠加定理、戴维南/诺顿等效、最大功率传输、节点/网孔分析、Δ-Y转换。学完这篇，再复杂的电路你也有办法下手。

> 作者在第5章引言里说："In this chapter we shall examine a number of theorems and techniques to help us analyze complex circuits and address specialized applications."（第144页，5.1 Introduction）
>
> 作者在第6章引言里说："Nodal analysis is the most general technique and can be applied to virtually any circuit. Mesh analysis is nearly as versatile and works well if only voltage sources are present. Both analysis methods generate a system of simultaneous linear equations."（第204页，6.1 Introduction）

## 一、电源转换——电压源和电流源的"身份互换"

### 1.1 什么是电源转换

一个理想电压源串联一个内阻$Z_s$，可以等效转换成一个理想电流源并联同一个内阻$Z_s$，反之亦然。

转换公式：

$$I_s = \frac{V_s}{Z_s}, \quad V_s = I_s \times Z_s$$

其中$V_s$是电压源的电压，$I_s$是电流源的电流，$Z_s$是内阻（转换前后保持不变）。

### 1.2 为什么需要电源转换

- 多个电压源串联时，直接相加就行；但多个电流源并联时，直接相加更方便
- 有时候把电压源转换成电流源，电路结构就从串联变成了并联，分析起来更简单
- 戴维南等效和诺顿等效本质上就是电源转换

### 1.3 生活类比

电源转换就像"供水方式"的转换：
- 电压源是"恒压水泵"——不管你用多少水，水压都保持不变（但有水管阻力=内阻）
- 电流源是"恒流水泵"——不管水压多大，流量都保持不变（但有水管阻力=内阻）
- 两种水泵可以等效转换，只要水压/流量/阻力满足转换公式

## 二、叠加定理——多电源"分而治之"

### 2.1 什么是叠加定理

> 作者说："the superposition theorem and it can be applied to any circuit or parameter that meets certain requirements, including circuits that have a mix of current sources and voltage sources."（第5章，约第155页）

叠加定理说：在一个有多个独立电源的线性电路中，任何一处的电压或电流，等于**每个电源单独作用时产生的电压/电流的代数和（复数和）**。

"单独作用"的意思是：
- 其他电压源**短路**（电压置0，保留内阻）
- 其他电流源**开路**（电流置0，保留内阻）

### 2.2 分析步骤

1. 选一个电源，把其他电源置零（电压源短路，电流源开路）
2. 计算这个电源单独作用时，目标位置的电压/电流
3. 对每个电源重复步骤1-2
4. 把所有结果**复数相加**（不是简单的数值相加！）

### 2.3 完整实例：双电源电路

**题目**：一个电路有两个电压源：$V_1 = 10\angle 0^\circ$ V 串联 $R_1 = 1k\Omega$，$V_2 = 5\angle 90^\circ$ V 串联 $R_2 = 2k\Omega$，两个支路并联后接负载 $R_L = 1k\Omega$。求负载电压$V_L$。

**解**：用叠加定理，分别算$V_1$和$V_2$单独作用时的负载电压。

**第一步：$V_1$单独作用（$V_2$短路）**

$V_2$短路后，$R_2$和$R_L$并联，再和$R_1$串联。

$$R_{parallel} = R_2 \parallel R_L = \frac{2000 \times 1000}{2000 + 1000} = 667 \Omega$$

$$V_{L1} = V_1 \times \frac{R_{parallel}}{R_1 + R_{parallel}} = 10\angle 0^\circ \times \frac{667}{1000 + 667} = 10 \times 0.4 = 4\angle 0^\circ \text{ V}$$

**第二步：$V_2$单独作用（$V_1$短路）**

$V_1$短路后，$R_1$和$R_L$并联，再和$R_2$串联。

$$R_{parallel2} = R_1 \parallel R_L = \frac{1000 \times 1000}{1000 + 1000} = 500 \Omega$$

$$V_{L2} = V_2 \times \frac{R_{parallel2}}{R_2 + R_{parallel2}} = 5\angle 90^\circ \times \frac{500}{2000 + 500} = 5\angle 90^\circ \times 0.2 = 1\angle 90^\circ \text{ V}$$

**第三步：叠加（复数相加）**

$$V_L = V_{L1} + V_{L2} = 4\angle 0^\circ + 1\angle 90^\circ = 4 + j1 = \sqrt{17}\angle 14.0^\circ = 4.12\angle 14.0^\circ \text{ V}$$

**结果**：负载电压幅值4.12V，相位14度。

**关键洞察**：如果直接用数值相加，$4+1=5$V，但实际是4.12V——因为两个电压相位不同（一个0度，一个90度），必须用复数相加。这就是叠加定理在AC电路里最容易出错的地方。

### 2.4 注意事项

- 叠加定理只适用于**线性电路**（电阻、电容、电感、线性受控源）
- 功率**不能**用叠加定理直接算（因为功率是电压/电流的平方，非线性）
- 受控源不能置零，要保留在电路里
- 所有运算都是复数运算

## 三、戴维南等效——把复杂电路"压缩"成一个电源+内阻

### 3.1 什么是戴维南定理

> 作者说："Using these theorems, entire circuits utilizing dozens of components can be reduced to a single source and impedance."（第5章，约第170页，5.4 Thèvenin's and Norton's Theorems）

戴维南定理说：任何线性电路，从负载两端看进去，都可以等效成**一个理想电压源串联一个内阻**。

- 等效电压源$V_{th}$：负载开路时，两端的电压（开路电压）
- 等效内阻$Z_{th}$：所有独立电源置零后，从负载两端看进去的阻抗

### 3.2 分析步骤

1. **移除负载**，在负载两端标记端口a和b
2. **算开路电压$V_{th}$**：负载开路时，a-b两端的电压
3. **算等效内阻$Z_{th}$**：所有独立电压源短路、电流源开路，从a-b看进去的阻抗
4. **画等效电路**：$V_{th}$串联$Z_{th}$，接上负载
5. **算负载电压/电流**：用欧姆定律

### 3.3 为什么戴维南等效这么有用

- **负载分析**：同一个电路接不同负载时，不用每次都重新分析整个电路，只需要用戴维南等效+欧姆定律
- **最大功率传输**：戴维南等效是计算最大功率传输条件的基础
- **阻抗匹配**：天线匹配、音频功放匹配，都需要先求源端的戴维南等效
- **电路化简**：把复杂的前级电路等效成简单的电源+内阻，后级分析就简单了

### 3.4 生活类比

戴维南等效就像"黑箱测试"：
- 你有一个复杂的电子设备（黑箱），它有一个输出接口
- 你不需要知道黑箱里面有什么，只需要测量两个量：开路时输出电压是多少（$V_{th}$），输出内阻是多少（$Z_{th}$）
- 知道了这两个量，你就能预测这个设备接任何负载时的表现——就这么简单

### 3.5 诺顿等效——戴维南的"电流源版本"

诺顿等效是戴维南等效的对偶形式：任何线性电路都可以等效成**一个理想电流源并联一个内阻**。

- 等效电流源$I_n$：负载短路时的电流（短路电流）
- 等效内阻$Z_n$：和戴维南内阻一样，$Z_n = Z_{th}$

诺顿等效和戴维南等效可以通过电源转换互相转换：$V_{th} = I_n \times Z_{th}$。

## 四、最大功率传输定理——负载取多少能获得最大功率？

### 4.1 定理内容

> 作者说："The concept of maximum power transfer in DC resistive circuits was presented in earlier work. While maximizing load power is not a goal of all circuit designs, it is important in certain applications."（第5章，约第185页，5.5 Maximum Power Transfer Theorem）

在AC电路中，当负载阻抗$Z_L$等于源端戴维南等效阻抗$Z_{th}$的**共轭复数**时，负载获得最大功率。

$$Z_L = Z_{th}^*$$

如果$Z_{th} = R_{th} + jX_{th}$，那么$Z_L = R_{th} - jX_{th}$。

最大功率值：

$$P_{max} = \frac{|V_{th}|^2}{4 R_{th}}$$

### 4.2 为什么是共轭匹配

- 负载的电抗部分和源的电抗部分**大小相等、符号相反**，互相抵消（谐振），电路呈纯阻性
- 负载的电阻部分等于源的电阻部分，此时功率最大（和DC情况一样）

### 4.3 实践应用

| 应用场景 | 为什么需要最大功率传输 |
|---|---|
| 音频功放接扬声器 | 功放输出阻抗通常很低（4-8Ω），扬声器也是4-8Ω，近似匹配 |
| 天线接接收机 | 天线阻抗通常是50Ω，接收机输入也是50Ω，精确匹配 |
| 射频电路级间匹配 | 每一级的输出阻抗和下一级的输入阻抗共轭匹配 |
| 电源设计 | 电源通常不需要最大功率传输（要的是高效率），而是低内阻稳压 |

**注意**：最大功率传输≠最高效率。最大功率传输时，效率只有50%（源内阻和负载电阻相等，各消耗一半功率）。电源设计追求的是高效率（>90%），所以电源内阻要远小于负载电阻，而不是匹配。

### 4.4 生活类比

最大功率传输就像"推秋千"：
- 推秋千的人有一个"固有频率"（源阻抗）
- 秋千也有一个"固有频率"（负载阻抗）
- 当两个频率匹配（共轭匹配）时，秋千荡得最高（功率最大）
- 如果频率不匹配，推的力大部分被浪费了，秋千荡不高

## 五、节点分析——SPICE仿真器的"底层算法"

### 5.1 什么是节点分析

> 作者说："Nodal analysis is the most general technique and can be applied to virtually any circuit."（第204页，6.1 Introduction）

节点分析（Nodal Analysis）是最通用的电路分析方法，几乎适用于任何电路。它的核心思想是：**对每个独立节点列KCL方程（流入电流=流出电流），解线性方程组得到各节点电压**。

### 5.2 分析步骤

1. **选参考节点**（通常是地，电位为0）
2. **标记其他节点**：$V_1, V_2, ..., V_n$
3. **对每个节点列KCL方程**：所有流出节点的电流之和=0
   - 电阻支路电流：$(V_i - V_j)/R$
   - 导纳支路电流：$(V_i - V_j) \times Y$
   - 电流源：直接加（流入为正，流出为负）
4. **解线性方程组**：得到各节点电压
5. **算各支路电流**：用欧姆定律

### 5.3 完整实例：三节点电路

**题目**：一个电路有3个节点（参考地+节点1+节点2）。节点1通过$R_1=1k\Omega$接$V_s=10\angle0^\circ$V，通过$R_2=2k\Omega$接节点2；节点2通过$R_3=1k\Omega$接地，通过$C=0.1\mu F$接地（频率1kHz）。求节点1和节点2的电压。

**解**：

第一步：算电容的导纳（1kHz时）

$$Y_C = j\omega C = j \times 6283 \times 0.1\times10^{-6} = j0.628 \text{ mS}$$

第二步：对节点1列KCL方程

从电压源经$R_1$流入节点1的电流 = 从节点1经$R_2$流出到节点2的电流

$$\frac{V_s - V_1}{R_1} = \frac{V_1 - V_2}{R_2}$$

代入数值：

$$\frac{10 - V_1}{1000} = \frac{V_1 - V_2}{2000}$$

整理：

$$2(10 - V_1) = V_1 - V_2 \implies 20 - 2V_1 = V_1 - V_2 \implies 3V_1 - V_2 = 20$$

第三步：对节点2列KCL方程

从节点1经$R_2$流入节点2的电流 = 从节点2经$R_3$流出到地的电流 + 从节点2经$C$流出到地的电流

$$\frac{V_1 - V_2}{R_2} = \frac{V_2}{R_3} + V_2 \times Y_C$$

代入数值：

$$\frac{V_1 - V_2}{2000} = \frac{V_2}{1000} + V_2 \times j0.628\times10^{-3}$$

两边乘2000：

$$V_1 - V_2 = 2V_2 + j1.256 V_2$$

整理：

$$V_1 - V_2(3 + j1.256) = 0$$

第四步：解方程组

$$\begin{cases} 3V_1 - V_2 = 20 \\ V_1 - (3+j1.256)V_2 = 0 \end{cases}$$

从第二个方程：$V_1 = (3+j1.256)V_2$

代入第一个方程：

$$3(3+j1.256)V_2 - V_2 = 20$$

$$(9 + j3.768 - 1)V_2 = 20$$

$$(8 + j3.768)V_2 = 20$$

$$V_2 = \frac{20}{8+j3.768} = \frac{20(8-j3.768)}{8^2+3.768^2} = \frac{160-j75.36}{78.2} = 2.05 - j0.964 = 2.26\angle -25.2^\circ \text{ V}$$

$$V_1 = (3+j1.256)(2.05-j0.964) = 6.15 - j2.89 + j2.57 + 1.21 = 7.36 - j0.32 = 7.37\angle -2.5^\circ \text{ V}$$

**结果**：节点1电压7.37V（相位-2.5度），节点2电压2.26V（相位-25.2度）。

### 5.4 用C语言实现节点分析（高斯消元）

节点分析的核心是解线性方程组。下面是一个用高斯消元法解复数线性方程组的C语言代码：

```c
#include <math.h>
#include <complex.h>

// 用高斯消元法解 n 元复数线性方程组 A*x = b
// A是n×n系数矩阵，b是常数项，x是解（输出）
// 返回0表示成功，-1表示矩阵奇异
int gaussian_solve_complex(int n, double complex A[][n], 
                             double complex b[], double complex x[])
{
    for (int col = 0; col < n; col++) {
        // 选主元（绝对值最大的行）
        int pivot = col;
        for (int row = col + 1; row < n; row++) {
            if (cabs(A[row][col]) > cabs(A[pivot][col])) {
                pivot = row;
            }
        }
        if (cabs(A[pivot][col]) < 1e-10) return -1; // 奇异矩阵
        
        // 交换行
        if (pivot != col) {
            for (int j = col; j < n; j++) {
                double complex tmp = A[col][j];
                A[col][j] = A[pivot][j];
                A[pivot][j] = tmp;
            }
            double complex tmp = b[col];
            b[col] = b[pivot];
            b[pivot] = tmp;
        }
        
        // 消元
        for (int row = col + 1; row < n; row++) {
            double complex factor = A[row][col] / A[col][col];
            for (int j = col; j < n; j++) {
                A[row][j] -= factor * A[col][j];
            }
            b[row] -= factor * b[col];
        }
    }
    
    // 回代
    for (int row = n - 1; row >= 0; row--) {
        double complex sum = b[row];
        for (int j = row + 1; j < n; j++) {
            sum -= A[row][j] * x[j];
        }
        x[row] = sum / A[row][row];
    }
    
    return 0;
}
```

> 这个函数就是SPICE（Simulation Program with Integrated Circuit Emphasis）仿真器的核心算法。SPICE做电路仿真时，就是把电路转换成节点电压方程组，然后用改进节点分析法（Modified Nodal Analysis，MNA）建立方程组，最后用高斯消元或LU分解求解。你用LTspice点一下"Run"，背后跑的就是这个算法。

## 六、其他方法速览

### 6.1 网孔分析（Mesh Analysis）

网孔分析是节点分析的对偶形式：对每个网孔列KVL方程，解网孔电流。适用于只有电压源的电路。和节点分析相比，网孔分析的方程数通常更少（网孔数<节点数时），但处理电流源比较麻烦。

### 6.2 Δ-Y转换（Delta-Wye Transformation）

三角形（Δ）连接和星形（Y）连接可以互相转换，用于化简三相电路和电桥电路。转换公式：

$$R_Y = \frac{R_{\Delta 相邻两支路的乘积}}{R_{\Delta 三条支路之和}}$$

$$R_{\Delta} = \frac{R_Y 两两乘积之和}{R_Y 对面支路}$$

在AC电路中，把R换成Z（阻抗）就行。

## 七、常见误区和坑

| 误区 | 正确理解 |
|---|---|
| 叠加定理算功率 | 功率不能叠加（非线性），必须先算出总电压/电流再算功率 |
| 戴维南等效时受控源也置零 | 独立源置零，受控源保留 |
| 最大功率传输=最高效率 | 最大功率传输时效率只有50%，电源设计要的是高效率不是最大功率 |
| AC电路最大功率传输时负载电阻=源电阻 | 是负载阻抗=源阻抗的共轭复数（电抗部分要抵消） |
| 节点分析时电流源方向搞反 | 流入节点为正，流出为负，列方程时要仔细 |
| 高斯消元不选主元 | 必须选主元（绝对值最大的行），否则数值不稳定 |
| 网孔分析处理电流源 | 电流源所在网孔的电流就是电流源电流，不需要列KVL方程 |

## 小结

这篇文章我们深入拆解了复杂AC电路的6种分析方法：

1. **电源转换**：电压源串联内阻 ↔ 电流源并联内阻，$I_s = V_s/Z_s$。用于简化电路结构。
2. **叠加定理**：多电源电路，每个电源单独作用算结果，最后复数相加。注意功率不能叠加。
3. **戴维南/诺顿等效**：任何线性电路等效成电压源+内阻（或电流源+内阻）。开路电压=等效电压，电源置零后的阻抗=等效内阻。
4. **最大功率传输**：负载阻抗=源阻抗的共轭复数时，负载获得最大功率，$P_{max} = |V_{th}|^2/(4R_{th})$。注意≠最高效率。
5. **节点分析**：最通用的方法，对每个节点列KCL方程，解线性方程组。SPICE仿真器的底层算法就是这个。附了C语言高斯消元的完整代码。
6. **网孔分析/Δ-Y转换**：节点分析的对偶形式和特殊电路化简方法，按需使用。

这些方法是分析复杂电路的"通用工具箱"。实际工作中，简单电路用串并联化简+戴维南，复杂电路直接用SPICE仿真（底层是节点分析），但理解这些方法的原理能帮你判断仿真结果对不对、电路为什么这么工作。

下一篇（第7篇），我们进入主题4的深度拆解：AC功率不只是P=UI——功率三角形、三相电和功率因数校正。我们会讲有功/无功/视在功率的区别、功率因数的意义、三相电为什么比单相电好、以及功率因数校正(PFC)电路的原理。
