## 开篇：为什么音箱放出来的声音和原声不一样？

你买了一对很贵的HiFi音箱，用它播放一首你熟悉的歌。你闭上眼睛听——嗯，高音很亮，低音很沉，人声很暖。但你总觉得，这和歌手在你面前现场唱的感觉还是不一样。

为什么？因为音箱是一个**系统**——输入是电信号，输出是声音。这个系统会改变信号：它会增强某些频率，衰减另一些频率，还会引入延迟和失真。换句话说，**任何系统都会对输入信号进行"加工"，输出是输入经过加工后的结果。**

在DSP中，我们最关心的是一类特殊的系统——**线性时不变系统（LTI系统）**。这类系统有一个神奇的性质：只要知道它的**冲激响应**（输入一个极短脉冲时的输出），就能计算出它对**任意输入**的输出。这个计算方法就是**卷积**。

卷积是DSP最重要的运算，没有之一。滤波、相关、特征提取、神经网络……几乎所有DSP算法都建立在卷积之上。这篇文章，我们就来彻底搞懂线性系统和卷积。

---

## 一、线性系统是什么？

### 系统的定义

> "A system is any process that produces an output signal in response to an input signal."
>
> ——第5章，第87页

翻译：系统是任何根据输入信号产生输出信号的过程。

系统无处不在：
- 音箱：输入电信号 → 输出声音
- 滤波器：输入含噪信号 → 输出去噪信号
- 放大器：输入小信号 → 输出大信号
- 房间：输入声音 → 输出带混响的声音
- 你的耳朵：输入声波 → 输出神经信号

![连续系统与离散系统框图](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_system_block.png)

*图：系统的基本结构。任何系统都有一个输入信号和一个输出信号。连续系统处理连续信号（用圆括号 x(t)），离散系统处理离散信号（用方括号 x[n]）。在DSP中，我们主要研究离散系统。*

**信号命名规则**（作者在第5章特别强调）：
- 连续信号用圆括号：`x(t)`、`y(t)`
- 离散信号用方括号：`x[n]`、`y[n]`
- 信号名用小写字母，大写字母预留给频域（如 X[k] 表示 x[n] 的傅里叶变换）
- 输入信号通常叫 `x`，输出信号通常叫 `y`

### 线性的两个条件

不是所有系统都是线性的。一个系统是线性的，必须同时满足两个条件：

**条件1：齐次性（Homogeneity）**
输入放大k倍，输出也放大k倍。
$$
T\{k \cdot x[n]\} = k \cdot T\{x[n]\}
$$

**条件2：可加性（Additivity）**
两个输入相加的输出，等于各自输出相加。
$$
T\{x_1[n] + x_2[n]\} = T\{x_1[n]\} + T\{x_2[n]\}
$$

两个条件合起来就是**叠加原理（Superposition）**：
$$
T\{a \cdot x_1[n] + b \cdot x_2[n]\} = a \cdot T\{x_1[n]\} + b \cdot T\{x_2[n]\}
$$

**生活类比**：线性系统就像一个公平的收银员——你买A商品花10元，买B商品花20元，一起买就是30元（可加性）；买两份A就是20元（齐次性）。非线性系统就像一个乱收费的收银员——买得多反而更贵，或者两件一起买收额外的"打包费"。

![线性系统的三个性质：齐次性、可加性、时不变性](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_linearity_properties.png)

*图：线性系统的三个核心性质。左：齐次性——输入放大k倍，输出也放大k倍；中：可加性——两个输入相加的输出等于各自输出相加；右：时不变性——输入延迟s个样本，输出也延迟s个样本，形状不变。*

### 叠加原理：DSP的分治策略

齐次性和可加性合起来，就是**叠加原理（Superposition）**——这是整个DSP的基础策略：把复杂信号分解成简单分量，每个分量单独处理，再把结果加起来。

![DSP的基本概念：分解→分别处理→合成（叠加原理）](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_superposition.png)

*图：DSP的基本概念——叠加原理。输入信号x[n]被分解成多个简单分量x0[n]、x1[n]、x2[n]，每个分量单独通过系统得到y0[n]、y1[n]、y2[n]，最后把这些输出分量合成（相加）得到最终输出y[n]。这个结果和直接把x[n]通过系统完全一样。这就是"分而治之"。*

> "Most DSP techniques are based on a divide-and-conquer strategy called superposition. The signal being processed is broken into simple components, each component is processed individually, and the results reunited."
>
> ——第5章，第87页

翻译：大多数DSP技术基于一种称为叠加的分治策略。被处理的信号被分解成简单的分量，每个分量被单独处理，然后结果重新合并。

**生活类比**：这就像算 2041 × 4——你不会直接在脑子里算四位数乘一位数，而是把2041分解成 2000 + 40 + 1，分别乘以4得到 8000 + 160 + 4，再加起来得到8164。DSP也是一样：把复杂信号分解成简单分量，分别处理，再加起来。

### 线性 vs 非线性系统

| 系统类型 | 特点 | 例子 | DSP处理方式 |
|---|---|---|---|
| 线性 | 满足叠加原理 | 理想放大器、理想滤波器、电阻电路 | 可以用卷积和傅里叶变换分析 |
| 非线性 | 不满足叠加原理 | 饱和、削波、调制、神经网络 | 不能直接用线性方法，需要特殊处理 |

### 静态线性：直观理解线性的第一种方式

齐次性和可加性是数学定义，但工程师更习惯用"静态线性"来直观判断：**当输入信号不随时间变化（直流/静态）时，输出和输入成正比，输入输出曲线是一条过原点的直线。**

> "The static response of a linear system is very simple: the output is the input multiplied by a constant. That is, a graph of the possible input values plotted against the corresponding output values is a straight line that passes through the origin."
>
> ——第5章，第92页

翻译：线性系统的静态响应非常简单：输出等于输入乘以一个常数。也就是说，把所有可能的输入值和对应的输出值画成图，是一条过原点的直线。

![静态线性的两个经典例子：欧姆定律和胡克定律](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_static_linearity.png)

*图：两个静态线性的经典例子。左：欧姆定律 I=V/R——电流和电压成正比，是一条过原点的直线；右：胡克定律 x=F/k——弹簧伸长量和拉力成正比，也是一条过原点的直线。这两个系统都是线性的。*

**无记忆系统（Memoryless System）**：如果一个系统的输出只取决于当前的输入，和历史输入无关，这个系统就叫无记忆系统。对于无记忆系统，只要满足静态线性（输入输出是过原点的直线），它就一定是线性系统。电阻就是典型的无记忆线性系统——瞬时电流只取决于瞬时电压。

### 正弦保真度：直观理解线性的第二种方式

线性系统还有一个神奇的性质：**如果输入是正弦波，输出也一定是正弦波，而且频率完全相同。** 只有幅度和相位可能改变。

> "If the input to a linear system is a sinusoidal wave, the output will also be a sinusoidal wave, and at exactly the same frequency as the input. Sinusoids are the only waveform that have this property."
>
> ——第5章，第94页

翻译：如果线性系统的输入是正弦波，输出也将是正弦波，且频率与输入完全相同。正弦波是唯一具有这个性质的波形。

这就是为什么我们用频率响应（幅频响应+相频响应）来描述线性系统——因为正弦波输入不会产生新的频率成分，只会被放大/衰减和相移。方波、三角波输入线性系统后，输出形状会改变（因为它们包含多个频率成分，每个成分被不同程度地放大和相移），但正弦波输入永远输出正弦波。

**工程师判断线性的土方法**：用正弦波发生器接输入，示波器接输出——
1. 输出是不是正弦波？（不能有削波、畸变）
2. 改变输入幅度，输出幅度是不是同比例变化？
3. 改变输入频率，输出频率是不是跟着变？

如果三个都满足，基本可以判断是线性系统（虽然不是严格的数学证明，但工程上足够可靠）。

### 非线性系统的例子

![非线性系统的两个例子：硅二极管和铁磁滞回线](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_nonlinear_examples.png)

*图：两个典型的非线性系统。左：硅二极管——电压和电流是指数关系，不是直线；右：铁的磁滞回线——磁通密度B和磁场强度H的关系取决于历史（磁滞），而且不是单值函数。这两个系统都不满足静态线性。*

**常见的非线性**：
- 放大器饱和（输入太大时输出不再增大）
- 比较器（输入大于阈值输出高，否则输出低）
- 调制（乘法器，两个信号相乘）
- 神经网络的激活函数（ReLU、sigmoid）

**好消息**：大多数工程应用中的系统，在工作点附近可以近似为线性系统。这就是为什么线性系统理论如此重要。

### 时不变性（Time Invariance）

时不变的意思是：系统的特性不随时间变化。如果输入延迟k个样本，输出也延迟k个样本，形状不变。

$$
y[n] = T\{x[n]\} \implies y[n-k] = T\{x[n-k]\}
$$

**线性 + 时不变 = LTI系统（Linear Time-Invariant）**

LTI系统是DSP中最重要的系统类别，因为它有一个非常强大的性质：**可以用冲激响应完全描述，输出等于输入和冲激响应的卷积。**

### 线性的特殊性质

线性系统还有几个经常被误解的特殊性质，作者在第5章专门做了澄清。

**性质1：交换律——级联顺序不重要**

当两个或多个线性系统级联（一个的输出是另一个的输入）时，总的输入输出关系和级联顺序无关。先A后B，和先B后A，结果完全一样。

> "When two or more linear systems are arranged in a cascade, the order of the systems does not affect the characteristics of the overall combination."
>
> ——第5章，第96页

翻译：当两个或多个线性系统级联时，系统的顺序不影响整体组合的特性。

![线性系统级联的交换律](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_commutative.png)

*图：线性系统级联的交换律。先经过系统A再经过系统B，和先经过系统B再经过系统A，最终输出y[n]完全相同。这就是为什么在电子电路中，先放大再滤波和先滤波再放大（理想情况下）结果一样。*

**生活类比**：就像穿衣服——先穿内衣再穿外套，和先穿外套再穿内衣（虽然奇怪），最终的"总层数"是一样的。当然，实际电路中有非线性效应（噪声、直流偏移、压摆率失真），顺序可能会有影响，但理想线性系统中顺序不重要。

**性质2：乘法的线性性——乘常数是线性的，乘信号是非线性的**

这是最容易被误解的一个点。乘法本身既可能是线性的，也可能是非线性的，关键看乘的是什么：

- **信号 × 常数** = 线性（这就是放大器或衰减器）
- **信号 × 信号** = 非线性（这就是调制器或混频器）

![乘法的线性性：乘常数是线性的，乘两信号是非线性的](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_multiplication.png)

*图：乘法的线性性判断。左：信号乘以常数k，输出y[n]=k·x[n]，满足齐次性和可加性，是线性运算（放大器）；右：两个信号相乘，输出y[n]=x1[n]·x2[n]，不满足叠加原理，是非线性运算（调制器）。*

为什么信号×信号是非线性的？想象输入是两个不同频率的正弦波相乘——输出会产生和频、差频等新的频率成分，这违反了正弦保真度（线性系统不会产生新频率）。调幅广播（AM）就是利用这个非线性原理，把音频信号"搬移"到高频载波上。

## 二、冲激函数和冲激响应

### 冲激函数（Delta Function）

离散冲激函数（也叫单位脉冲、δ函数）的定义非常简单：

$$
\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases}
$$

就是说，只有在n=0时是1，其他时候都是0。

> "An impulse is a signal composed of all zeros, except a single nonzero point."
>
> ——第6章，第107页

翻译：冲激是一个由全零组成的信号，除了单个非零点。

**生活类比**：冲激就像敲一下鼓——"咚"的一声，时间极短，能量集中在一个瞬间。它是信号世界里的"基本粒子"，所有信号都可以分解成冲激的加权和。

### 信号的冲激分解

任何离散信号都可以表示为冲激的加权和：

$$
x[n] = \sum_{k=-\infty}^{\infty} x[k] \cdot \delta[n-k]
$$

这看起来很显然——x[k]就是第k个样本的值，δ[n-k]就是在第k个位置的冲激。但这个分解是卷积的基础。

**生活类比**：这就像把一幅画分解成一个个像素——每个像素有自己的颜色和位置，把所有像素拼起来就是完整的画。冲激分解就是把信号分解成一个个"样本像素"。

![信号的冲激分解：每个样本就是一个缩放平移后的冲激](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_impulse_decomposition.png)

*图：信号的冲激分解。左上角是原始信号x[n]，其余每个子图是一个分量——第k个分量只有在位置k处有值x[k]，其他位置都是0，即 x[k]·δ[n-k]。把所有分量加起来就还原了原始信号。这就是卷积的基础。*

### 其他信号分解方式

冲激分解是DSP中最重要的分解方式（因为它直接导出卷积），但作者在第5章还介绍了几种其他的分解方式，了解它们有助于拓宽思路。

![其他三种常见信号分解方式：阶跃分解、奇偶分解、交织分解](https://raw.githubusercontent.com/Jankin-Bai/jankin-bai.github.io/main/images/dsp/ch5_other_decompositions.png)

*图：三种其他信号分解方式。左：阶跃分解——每个分量是一个阶跃函数，幅度为相邻样本的差；中：奇偶分解——信号分解为对称的偶分量和反对称的奇分量；右：交织分解——按样本序号的奇偶拆分成两个子序列，这是FFT算法的核心思想！*

| 分解方式 | 分量形式 | 主要用途 |
|---|---|---|
| 冲激分解 | N个冲激 x[k]·δ[n-k] | 卷积、系统分析（最重要） |
| 阶跃分解 | N个阶跃 (x[k]-x[k-1])·u[n-k] | 阶跃响应分析、边缘检测 |
| 奇偶分解 | 偶分量 + 奇分量 | 傅里叶变换的实数/虚数性质分析 |
| 交织分解 | 偶数样本 + 奇数样本 | FFT快速傅里叶变换（蝶形运算） |
| 傅里叶分解 | 不同频率的正弦波之和 | 频域分析、滤波（后面主题详细讲） |

**关键洞察**：分解的目的是"分而治之"——把复杂问题拆成简单问题。如果一种分解不能简化问题，那它就没有价值。冲激分解之所以最重要，是因为LTI系统对冲激的响应（冲激响应）可以完全描述系统，从而把"任意输入的输出"这个复杂问题，简化为"冲激响应的缩放平移求和"这个简单问题。

### 冲激响应（Impulse Response）

冲激响应就是：**当系统的输入是单位冲激时，系统的输出。**

通常用h[n]表示冲激响应。

$$
h[n] = T\{\delta[n]\}
$$

为什么冲激响应这么重要？因为对于LTI系统：

> **知道了冲激响应，就能计算出系统对任意输入的输出。**

这就是LTI系统的神奇之处——一个信号（冲激响应）就能完全描述整个系统。

**生活类比**：冲激响应就像一个人的"声音指纹"——你在房间里拍一下手（冲激输入），录下房间的回声（冲激响应）。有了这个回声记录，你就能计算出任何声音在这个房间里听起来是什么样的——歌手的歌声、交响乐、说话声，都可以通过和冲激响应卷积得到。

## 三、卷积：DSP最重要的运算

### 卷积的定义

对于LTI系统，输出y[n]等于输入x[n]和冲激响应h[n]的卷积：

$$
y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] \cdot h[n-k]
$$

这个公式看起来有点抽象，我们用两种方式来理解它。

> "Convolution is a mathematical way of combining two signals to form a third signal. It is the single most important technique in Digital Signal Processing... Convolution provides the mathematical framework for DSP; there is nothing more important in this book."
>
> ——第6章，第107页

翻译：卷积是一种将两个信号组合成第三个信号的数学方法。它是数字信号处理中最重要的技术……卷积为DSP提供了数学框架；这本书中没有比它更重要的了。

### 理解方式1：输入侧算法（Input Side Algorithm）

输入侧算法的思路是：**把输入分解成冲激，每个冲激经过系统产生一个缩放和平移的冲激响应，把所有输出加起来。**

步骤：
1. 输入信号x[n]的每个样本x[k]，可以看作一个幅度为x[k]、位置在k的冲激
2. 这个冲激经过系统，产生输出 x[k] · h[n-k]（幅度缩放x[k]，位置平移k）
3. 把所有k的输出加起来，就是总输出y[n]

$$
y[n] = \sum_{k} \underbrace{x[k]}_{\text{输入幅度}} \cdot \underbrace{h[n-k]}_{\text{平移后的冲激响应}}
$$

**生活类比**：这就像合唱——每个歌手（输入样本）在不同时间（位置k）开始唱，声音大小不同（幅度x[k]，每个人的声音都有自己的音色（冲激响应h[n]），在大厅里产生回声（平移h[n-k]）。把所有歌手的声音加起来，就是最终的合唱效果（输出y[n]）。

### 理解方式2：输出侧算法（Output Side Algorithm）

输出侧算法的思路是：**计算每个输出样本时，看它是哪些输入样本和哪些冲激响应样本的乘积之和。**

对于输出y[n]：
1. 把冲激响应h[k]翻转（变成h[-k]）
2. 把翻转后的冲激响应平移到位置n（变成h[n-k]）
3. 和输入x[k]逐点相乘
4. 把所有乘积加起来，就是y[n]

这就是卷积公式的直接计算方式。

**生活类比**：这就像算一笔账——每个月的支出（输出y[n]），等于这个月之前每笔收入（输入x[k]）乘以它在这个月还剩下的比例（冲激响应h[n-k]），然后全部加起来。比如你1月收入1000元，每月花掉一半（h[0]=1, h[1]=0.5, h[2]=0.25...），那么3月的支出就是1月收入×0.25 + 2月收入×0.5 + 3月收入×1。

### 卷积的几何意义

卷积的几何意义可以用"翻转-平移-相乘-求和"四步来理解：

对于每个输出位置n：
1. **翻转**：把h[k]沿纵轴翻转，得到h[-k]
2. **平移**：把翻转后的h向右平移n个位置，得到h[n-k]
3. **相乘**：x[k]和h[n-k]逐点相乘
4. **求和**：把所有乘积加起来，得到y[n]

**为什么要翻转？** 因为冲激响应描述的是"输入一个冲激后，输出随时间的变化"。当计算输出n时，更早的输入k（k<n）对当前输出的贡献，是冲激响应中更靠后的部分（n-k更大）。所以需要翻转。

## 四、卷积的性质

### 交换律（Commutative）

$$
x[n] * h[n] = h[n] * x[n]
$$

卷积的两个输入可以交换，结果相同。这意味着：输入信号和冲激响应谁在前谁在后都一样。

**生活类比**：就像乘法交换律——3×5=5×3，谁乘谁都一样。

### 结合律（Associative）

$$
(x[n] * h_1[n]) * h_2[n] = x[n] * (h_1[n] * h_2[n])
$$

多个系统级联时，总的冲激响应等于各个冲激响应的卷积。而且级联顺序不影响总的冲激响应（因为交换律）。

**生活类比**：就像穿衣服——先穿内衣再穿外套，和先穿外套再穿内衣（虽然奇怪），最终的"总效果"是一样的。系统级联也是，顺序不影响总的输入输出关系。

### 分配律（Distributive）

$$
x[n] * (h_1[n] + h_2[n]) = x[n] * h_1[n] + x[n] * h_2[n]
$$

两个系统并联时，总的冲激响应等于各个冲激响应之和。

**生活类比**：就像两条路并行——总车流量等于两条路的车流量之和。

### 与冲激的卷积

$$
x[n] * \delta[n] = x[n]
$$

任何信号和冲激卷积，结果还是它自己。这是因为冲激响应是δ的系统就是"直通系统"（输入等于输出）。

### 与阶跃的卷积

$$
x[n] * u[n] = \sum_{k=-\infty}^{n} x[k]
$$

信号和阶跃函数卷积，等于对信号做累加（离散积分）。这是因为阶跃响应是累加器。

## 五、常见冲激响应

| 冲激响应 | 系统类型 | 作用 |
|---|---|---|
| δ[n] | 直通系统 | 输入等于输出 |
| δ[n-k] | 纯延迟 | 输出延迟k个样本 |
| 常数（有限长） | 移动平均 | 低通滤波，平滑信号 |
| 指数衰减 a^n u[n] | 一阶递归 | 简单低通/高通 |
| sinc函数 | 理想低通 | 完美低通滤波（非因果） |
| 正弦波 | 谐振器 | 选频，只让特定频率通过 |

### 例子：移动平均滤波器

移动平均是最简单的FIR滤波器，冲激响应是N个常数：

$$
h[n] = \begin{cases} 1/N, & 0 \le n < N \\ 0, & \text{其他} \end{cases}
$$

它的作用是：输出等于最近N个输入的平均值。这能平滑信号、去除高频噪声，但也会使信号的快速变化变慢。

**生活类比**：移动平均就像算最近N天的平均气温——每天的气温波动被平滑了，能看到长期趋势，但突然的降温也被延迟了。

## 六、完整实例计算

### 例子：简单卷积计算

给定输入 x = [1, 2, 3]，冲激响应 h = [4, 5]，计算卷积 y = x * h。

**用输入侧算法：**
- x[0]=1 产生输出：[4, 5, 0, 0]（1×h，位置0开始）
- x[1]=2 产生输出：[0, 8, 10, 0]（2×h，位置1开始）
- x[2]=3 产生输出：[0, 0, 12, 15]（3×h，位置2开始）
- 相加：y = [4, 5+8, 10+12, 15] = [4, 13, 22, 15]

**验证（输出侧算法）：**
- y[0] = x[0]×h[0] = 1×4 = 4
- y[1] = x[0]×h[1] + x[1]×h[0] = 1×5 + 2×4 = 13
- y[2] = x[1]×h[1] + x[2]×h[0] = 2×5 + 3×4 = 22
- y[3] = x[2]×h[1] = 3×5 = 15

结果一致：y = [4, 13, 22, 15]

**卷积长度**：长度为M的输入和长度为N的冲激响应卷积，输出长度为M+N-1。

### C语言实现

```c
// 卷积计算：输入x[M]，冲激响应h[N]，输出y[M+N-1]
void convolution(const double *x, int M,
                 const double *h, int N,
                 double *y)
{
    // 初始化输出为0
    for (int i = 0; i < M + N - 1; i++) {
        y[i] = 0.0;
    }

    // 输入侧算法：每个输入样本产生一个缩放平移的冲激响应
    for (int k = 0; k < M; k++) {
        for (int j = 0; j < N; j++) {
            y[k + j] += x[k] * h[j];
        }
    }
}
```

这个实现的时间复杂度是O(M×N)。当M和N很大时（比如音频处理中M=10000, N=1024），直接卷积会很慢。这时候就需要用FFT实现快速卷积（时间复杂度O((M+N)log(M+N))），我们会在后面的主题中讲到。

## 七、常见误区与坑

| 误区 | 正确理解 |
|---|---|
| "卷积就是相关" | 卷积需要翻转冲激响应，相关不需要翻转；互相关=x[n]*h[-n] |
| "卷积只能用于滤波" | 卷积是LTI系统的通用运算，滤波只是其中一个应用；相关、特征提取、神经网络都用卷积 |
| "FIR和IIR的卷积计算方法一样" | FIR用直接卷积（有限长冲激响应），IIR用差分方程递归计算（冲激响应无限长） |
| "卷积的结果长度和输入一样" | 卷积结果长度是M+N-1，比输入长；实际应用中需要处理边界（补零/循环卷积） |
| "冲激响应就是系统的输出" | 冲激响应是**输入为冲激时**的输出，不是任意输入的输出 |
| "所有系统都可以用卷积描述" | 只有LTI（线性时不变）系统可以用卷积描述；非线性或时变系统不行 |
| "卷积翻转是多此一举" | 翻转是因果系统的必然结果——过去的输入对当前输出的贡献，对应冲激响应中靠后的部分 |
| "直接卷积太慢，都要用FFT" | 当冲激响应很短（如<32点）时，直接卷积比FFT卷积更快，因为FFT有额外开销 |

## 小结

这篇是【DSP系列】核心主题2，我们搞懂了DSP最重要的运算——线性系统与卷积：

1. **线性系统**：满足齐次性和可加性（叠加原理）的系统；线性+时不变=LTI系统，是DSP的核心研究对象
2. **冲激响应**：输入为单位冲激时系统的输出；对于LTI系统，冲激响应能完全描述系统
3. **卷积**：输出=输入*冲激响应；可以用输入侧算法（分解输入）或输出侧算法（翻转-平移-相乘-求和）理解
4. **卷积性质**：交换律、结合律、分配律；多个系统级联的总冲激响应是各冲激响应的卷积
5. **常见冲激响应**：移动平均（低通平滑）、指数衰减（一阶递归）、sinc（理想低通）

**最重要的三句话**：
- **卷积是DSP最重要的运算，没有之一**——滤波、相关、特征提取、神经网络都建立在卷积之上
- **LTI系统可以用冲激响应完全描述**——知道了冲激响应，就能计算任意输入的输出
- **卷积的几何意义是翻转-平移-相乘-求和**——理解了这四步，就理解了卷积

下一篇（第6篇），我们进入DSP的第二大核心工具——**傅里叶变换与DFT/FFT**。卷积让我们在时域处理信号，傅里叶变换让我们从频域看信号，发现时域中看不到的规律。这两个工具合起来，就是DSP的完整工具箱。
