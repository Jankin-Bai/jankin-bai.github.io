## 开篇：你手机里的"数字暗房"和"数字调音台"

你用手机拍了一张夜景照片，太暗了。你打开修图软件，点一下"增强"——照片瞬间变亮了，噪点少了，细节清晰了。你很好奇：软件做了什么？

答案是**数字图像处理**——用卷积和傅里叶变换对图像的像素进行处理，就像我们之前对一维信号做的那样，只不过图像是二维的。

同样，你用手机听音乐，打开均衡器，把低音调高、高音调低，音乐的味道立刻变了。这是**数字音频处理**——用数字滤波器改变音频的频率响应。

音频和图像处理是DSP最直观、最常见的应用。学了这么多理论（卷积、傅里叶变换、滤波器），这篇我们终于能看到实际效果了——音频处理能听到，图像处理能看到。

## 一、音频处理基础

### 音频处理的三个领域

> "Audio processing covers many diverse fields, all involved in presenting sound to human listeners. Three areas are prominent: (1) high fidelity music reproduction, such as in audio compact discs, (2) voice telecommunications, another name for telephone networks, and (3) synthetic speech, where computers generate and recognize human voice patterns."
>
> ——第22章，第351页

翻译：音频处理涵盖许多不同领域，都涉及向人类听众呈现声音。三个突出的领域是：（1）高保真音乐再现，如音频CD；（2）语音电信，即电话网络；（3）合成语音，计算机生成和识别人类语音模式。

| 领域 | 目标 | 关键技术 | 典型应用 |
|---|---|---|---|
| **高保真音乐** | 尽可能还原原始声音 | 高采样率、高分辨率、无损压缩 | CD、流媒体音乐、HiFi音响 |
| **语音通信** | 在有限带宽下清晰传输语音 | 语音编码、降噪、回声消除 | 电话、视频会议、对讲机 |
| **语音合成/识别** | 让计算机能说能听 | 语音合成（TTS）、语音识别（ASR） | 智能助手、导航、无障碍 |

### 人耳听觉特性

音频处理的"裁判"是人耳——所有技术都要围绕人耳的听觉特性来设计。

| 特性 | 说明 | 对DSP的影响 |
|---|---|---|
| **频率范围** | 人耳约20Hz~20kHz | 采样率44.1kHz（CD）就能覆盖 |
| **动态范围** | 约120dB（从听阈到痛阈） | 需要16位以上量化（16位约98dB） |
| **对数感知** | 响度和频率都是对数感知 | 用dB表示幅度，用倍频程表示频率 |
| **掩蔽效应** | 强音能掩蔽同时存在的弱音 | 心理声学模型，MP3压缩的基础 |
| **双耳定位** | 用两耳的时间差和强度差定位 | 空间音频、3D音效、立体声 |
| **哈斯效应** | 先到达的声音决定方向 | 延迟、混响、声场设计 |

**生活类比**：人耳就像一个有特殊偏好的评委——它对某些频率（2-5kHz）特别敏感，对某些频率（低频和极高频）不敏感；它会被强音"带偏"（掩蔽效应）；它用两只耳朵"三角定位"。音频DSP就是要讨好这个评委，在它敏感的地方多花功夫，在它不敏感的地方省力气。

## 二、音频DSP应用

### 1. 均衡器（Equalizer）

均衡器是最常见的音频效果器——调整不同频段的增益，改变声音的"味道"。

**实现方式**：
- 图形均衡器：多个固定频段（如31段），每段独立调节增益
- 参数均衡器：可调中心频率、Q值、增益，更灵活
- 用IIR滤波器（双二阶节级联）实现

**生活类比**：均衡器就像调色板——低音是红色（温暖），中音是绿色（自然），高音是蓝色（明亮）。你可以通过调整三原色的比例，调出想要的色调。

### 2. 动态范围压缩（Compressor）

压缩器减小音频的动态范围——把大声的部分压小，把小声的部分相对提升，让整体音量更均匀。

**参数**：
- 阈值（Threshold）：超过阈值的部分被压缩
- 比率（Ratio）：压缩比例，如4:1表示超过阈值4dB，输出只增加1dB
- 攻击时间（Attack）：信号超过阈值后，压缩器开始工作的时间
- 释放时间（Release）：信号低于阈值后，压缩器恢复的时间

**应用**：播客、广播、流行音乐（让声音更"贴耳"）、助听器

**生活类比**：压缩器就像自动音量控制——有人大声喊时，自动把音量调小；有人小声说话时，自动把音量调大。这样你就不用频繁手动调音量了。

### 3. 降噪（Noise Reduction）

从含噪语音中去除背景噪声，提高信噪比。

**方法**：
- 谱减法：估计噪声频谱，从信号频谱中减去
- 维纳滤波：最优线性滤波，最小化均方误差
- 自适应滤波：根据信号特性自动调整滤波器系数
- 深度学习：用神经网络做降噪（如RNNoise）

**应用**：电话降噪、视频会议、助听器、录音后期

### 4. 混响（Reverb）

模拟声音在房间中的反射和衰减，给声音增加"空间感"。

**实现方式**：
- 卷积混响：用真实房间的冲激响应和干声卷积
- 算法混响：用延迟线、反馈网络模拟（如Schroeder混响）
- 参数：房间大小、衰减时间、干湿比、预延迟

**生活类比**：混响就像给声音"加背景"——在浴室里唱歌声音洪亮（混响强），在旷野里唱歌声音干涩（混响弱）。数字混响就是在计算机里模拟各种房间的声学特性。

### 5. 其他音频效果

| 效果 | 原理 | 应用 |
|---|---|---|
| **延迟（Delay）** | 信号延迟一段时间后叠加 | 回声、合唱、镶边 |
| **合唱（Chorus）** | 多个微差延迟的信号叠加 | 让单音听起来像多个乐器 |
| **镶边（Flanger）** | 可变延迟的信号叠加 | 喷气式飞机飞过的声音效果 |
| **相位（Phaser）** | 全通滤波器改变相位后叠加 | 迷幻、太空感的声音 |
| **变调（Pitch Shift）** | 改变音高而不改变速度 | 卡拉OK变调、修音 |
| **时间拉伸（Time Stretch）** | 改变速度而不改变音高 | 快速播放、慢动作 |

## 三、图像形成与显示

### 图像的数字化

图像是二维信号——x和y是空间坐标，像素值是亮度或颜色。

和一维信号一样，图像数字化也需要：
- **空间采样**：决定分辨率（如1920×1080）
- **幅值量化**：决定位深（如8位=256级灰度，24位=1677万色）

**生活类比**：图像数字化就像用马赛克拼贴画——采样决定马赛克的颗粒粗细（分辨率），量化决定每种颜色有多少种选择（位深）。颗粒越细、颜色越多，拼出来的画越逼真。

### 色彩空间

| 色彩空间 | 说明 | 应用 |
|---|---|---|
| **RGB** | 红、绿、蓝三通道，加色模型 | 显示器、数码相机 |
| **CMYK** | 青、品红、黄、黑，减色模型 | 印刷 |
| **YUV/YCbCr** | 亮度(Y)+色差(U/V)，人眼对亮度更敏感 | 视频压缩、JPEG |
| **HSV/HSL** | 色相、饱和度、明度/亮度 | 图像处理、调色 |

**为什么用YUV？** 因为人眼对亮度（Y）比对色度（UV）更敏感，所以可以对色度降采样（如4:2:0），在不明显降低画质的情况下减少数据量。这是JPEG和视频压缩的基础。

### 图像传感器

数码相机和手机的图像传感器（CCD/CMOS）把光转换成电信号，再ADC转换成数字像素值。

DSP在图像传感器中的应用：
- 去马赛克（Demosaic）：从Bayer阵列重建全彩色图像
- 白平衡：校正不同光源下的色彩偏差
- 降噪：去除传感器的热噪声和散粒噪声
- 锐化：增强边缘，补偿光学模糊
- HDR：多帧合成高动态范围图像
- 自动曝光/自动对焦/自动白平衡（3A算法）

## 四、线性图像处理

### 图像卷积：二维卷积

> "Linear image processing is based on the same two techniques as conventional DSP: convolution and Fourier analysis. Convolution is the more important of these two, since images have their information encoded in the spatial domain rather than the frequency domain."
>
> ——第24章，第397页

翻译：线性图像处理基于与传统DSP相同的两种技术：卷积和傅里叶分析。卷积是这两者中更重要的，因为图像的信息编码在空间域而不是频域。

图像卷积是一维卷积的二维扩展：
- 一维：输出 = 输入 × 冲激响应（一维卷积）
- 二维：输出图像 = 输入图像 × 滤波器核（二维卷积）

$$
y[i,j] = \sum_{m} \sum_{n} x[i-m, j-n] \cdot h[m,n]
$$

其中$h[m,n]$是二维滤波器核（通常是3×3或5×5的小矩阵）。

**生活类比**：图像卷积就像用一个小印章在大画上盖章——印章（滤波器核）在画（输入图像）上移动，每个位置的输出是印章覆盖区域的加权平均。不同的印章（不同的核）能产生不同的效果——模糊、锐化、边缘检测。

### 常见图像滤波器

| 滤波器 | 3×3核 | 效果 |
|---|---|---|
| **均值滤波** | 全1除以9 | 图像模糊、去噪 |
| **高斯滤波** | 高斯分布加权 | 更自然的模糊，保留边缘更好 |
| **锐化** | 中心大、周围负 | 增强边缘，图像更清晰 |
| **Sobel边缘检测** | 水平/垂直梯度核 | 检测水平/垂直边缘 |
| **Laplacian** | 四邻域或八邻域负，中心正 | 检测所有方向的边缘 |
| **浮雕（Emboss）** | 非对称核 | 产生浮雕效果 |

### 可分离卷积（Separable Convolution）

二维卷积的计算量很大——一个N×N的核和M×M的图像卷积，需要O(M²N²)次运算。

但有些核是**可分离的**——可以分解成两个一维核的外积：
$$
h[m,n] = h_{row}[m] \cdot h_{col}[n]
$$

例如，高斯核、均值核都是可分离的。可分离卷积的计算量从O(M²N²)降到O(M²N)，快很多。

**生活类比**：可分离卷积就像先横向抹墙、再纵向抹墙——比用方形抹子一点点抹快得多。高斯模糊和均值模糊都可以这样做。

### FFT卷积

对于大核（如大半径高斯模糊），可以用FFT实现快速卷积——和一维FFT卷积一样，利用卷积定理：
1. 对图像和核做二维FFT
2. 频域相乘
3. 二维逆FFT

当核很大时，FFT卷积比直接卷积快得多。

## 五、特殊成像技术

### CT（计算机断层扫描）

CT的原理：X射线绕人体旋转，从数百个角度采集投影数据，然后用DSP算法重建出人体内部的横截面图像。

**核心算法**：
- 滤波反投影（Filtered Back Projection, FBP）：先对投影滤波，再反投影重建
- 迭代重建：用迭代算法优化重建质量，降低辐射剂量

**DSP的作用**：
- 傅里叶切片定理：投影的傅里叶变换等于图像傅里叶变换的一个切片
- 滤波：用斜坡滤波器补偿反投影的模糊
- 降噪：降低低剂量CT的噪声

### MRI（磁共振成像）

MRI的原理：用强磁场和射频脉冲激发人体中的氢原子，接收回波信号，用傅里叶变换重建图像。

**DSP的作用**：
- 二维傅里叶变换：从k空间（频率空间）数据重建图像
- 脉冲序列设计：激发、编码、采集的时序设计
- 图像重建：快速成像（如压缩感知、并行成像）

### 超声成像

超声的原理：发射超声波，接收组织反射的回波，根据回波的时间和强度重建图像。

**DSP的作用**：
- 脉冲压缩：用匹配滤波提高距离分辨率
- 波束形成：用相控阵聚焦超声波束
- 多普勒处理：检测血流速度（频移）
- 图像重建：B模式（灰度）、M模式（运动）、彩色多普勒

**生活类比**：这三种成像技术就像三种不同的"透视眼"——CT是X射线旋转扫描（像切片面包），MRI是用磁场"摇"氢原子然后听回声（像敲钟听音色），超声是用超声波"敲"人体然后听回声（像蝙蝠回声定位）。三种技术都用DSP把采集到的信号变成我们能看懂的图像。

## 六、完整实例：图像卷积滤波

```python
import numpy as np
from PIL import Image
import matplotlib.pyplot as plt

# 1. 读取图像并转灰度
img = Image.open('test.jpg').convert('L')
x = np.array(img, dtype=np.float64)

# 2. 定义3x3滤波器核
# 均值滤波（模糊）
kernel_blur = np.ones((3,3)) / 9

# 锐化
kernel_sharpen = np.array([
    [ 0, -1,  0],
    [-1,  5, -1],
    [ 0, -1,  0]
])

# Sobel边缘检测（水平）
kernel_sobel = np.array([
    [-1, 0, 1],
    [-2, 0, 2],
    [-1, 0, 1]
])

# 3. 二维卷积函数
def convolve2d(image, kernel):
    h, w = image.shape
    kh, kw = kernel.shape
    pad_h, pad_w = kh//2, kw//2
    
    # 零填充
    padded = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant')
    
    # 卷积
    output = np.zeros_like(image)
    for i in range(h):
        for j in range(w):
            output[i,j] = np.sum(padded[i:i+kh, j:j+kw] * kernel)
    
    return output

# 4. 应用各种滤波器
img_blur = convolve2d(x, kernel_blur)
img_sharp = convolve2d(x, kernel_sharpen)
img_edges = np.abs(convolve2d(x, kernel_sobel))

# 5. 显示结果
fig, axes = plt.subplots(2, 2, figsize=(12, 10))
axes[0,0].imshow(x, cmap='gray'); axes[0,0].set_title('原图')
axes[0,1].imshow(img_blur, cmap='gray'); axes[0,1].set_title('均值滤波（模糊）')
axes[1,0].imshow(img_sharp, cmap='gray'); axes[1,0].set_title('锐化')
axes[1,1].imshow(img_edges, cmap='gray'); axes[1,1].set_title('Sobel边缘检测')
plt.show()
```

这个例子展示了图像卷积的威力——用不同的3×3核，就能实现模糊、锐化、边缘检测等完全不同的效果。这就是为什么卷积是图像处理的核心。

## 七、常见误区与坑

| 误区 | 正确理解 |
|---|---|
| "图像处理和一维DSP完全不同" | 图像处理是二维DSP，核心技术还是卷积和傅里叶变换，只是从一维扩展到二维 |
| "图像卷积就是把像素变模糊" | 卷积可以实现很多效果——模糊、锐化、边缘检测、浮雕、增强，取决于滤波器核 |
| "音频压缩就是把文件变小" | 音频压缩利用人耳的心理声学特性，去掉人耳听不到的成分，在不明显降低音质的情况下减小文件 |
| "降噪就是把噪声频率去掉" | 降噪比简单滤波复杂——语音和噪声的频谱经常重叠，需要用谱减法、维纳滤波、自适应滤波或深度学习 |
| "CT/MRI/超声是医学设备，和DSP无关" | 这些设备的核心就是DSP——从采集的信号重建图像，没有DSP就没有现代医学影像 |
| "图像分辨率越高越好" | 分辨率越高，数据量越大，处理越慢；根据应用需求选择合适的分辨率 |
| "8位色深足够了" | 8位（256级）对普通显示足够，但对图像处理（如HDR、专业修图）不够，需要16位或更高 |
| "FFT卷积总是比直接卷积快" | 当核很小时（如3×3），直接卷积更快，因为FFT有额外开销；核大时FFT才快 |

## 小结

这篇是【DSP系列】核心主题6，我们看到了DSP在音频和图像处理中的实际应用：

1. **音频处理**：三个领域（高保真音乐、语音通信、语音合成/识别），人耳听觉特性是设计的依据；均衡器、压缩器、降噪、混响是常见效果
2. **图像形成**：图像数字化（空间采样+幅值量化）、色彩空间（RGB/CMYK/YUV/HSV）、图像传感器中的DSP（去马赛克、白平衡、降噪、3A）
3. **线性图像处理**：二维卷积是核心，不同的核实现不同效果（模糊/锐化/边缘检测）；可分离卷积和FFT卷积加速计算
4. **特殊成像技术**：CT（滤波反投影）、MRI（二维傅里叶重建）、超声（脉冲压缩、波束形成、多普勒），核心都是DSP

**最重要的三句话**：
- **音频和图像处理是DSP最直观的应用**——音频能听到，图像能看到，理论终于变成了可感知的效果
- **图像卷积是一维卷积的二维扩展**——核心思想完全一样，只是从一维信号变成了二维像素矩阵
- **现代医学影像（CT/MRI/超声）的核心就是DSP**——没有DSP算法，采集到的原始信号无法变成我们能看懂的图像
