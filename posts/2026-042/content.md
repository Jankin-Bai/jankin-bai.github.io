## 开篇：为什么降噪耳机能"安静"地让你听歌？

你戴上降噪耳机，按下降噪按钮——周围的地铁轰鸣声、人群嘈杂声瞬间消失了，只剩下清澈的音乐。你很好奇：耳机是怎么做到的？

答案是**数字滤波器**。降噪耳机里有一个麦克风采集环境噪声，然后用数字滤波器产生一个和噪声反相的信号，和音乐一起播放——噪声和反相信号相互抵消，你就听不到噪声了。

滤波器是DSP最常见、最重要的应用。可以说，你每天接触的电子设备——手机、耳机、电视、汽车、医疗设备——里面都有数字滤波器在工作。

数字滤波器分为两大类：**FIR（有限冲激响应）**和**IIR（无限冲激响应）**。这篇我们先讲FIR——它设计简单、绝对稳定、可以实现线性相位，是大多数应用的首选。

## 一、数字滤波器基础

### 滤波器的两个用途

> "Digital filters are used for two general purposes: (1) separation of signals that have been combined, and (2) restoration of signals that have been distorted in some way."
>
> ——第14章，第261页

翻译：数字滤波器有两个通用用途：（1）分离混合在一起的信号；（2）恢复以某种方式失真的信号。

| 用途 | 说明 | 例子 |
|---|---|---|
| **信号分离** | 从混合信号中提取想要的部分，去掉不想要的部分 | 从含噪语音中去掉背景噪声；从心电图中去掉工频干扰；从无线电信号中选出特定电台 |
| **信号恢复** | 补偿信号在传输或采集过程中的失真 | 补偿通信信道的频率失真；修复老唱片的高频损失；校正传感器的非线性 |

### 滤波器的分类

按频率响应分类：

| 类型 | 作用 | 生活类比 |
|---|---|---|
| **低通（LPF）** | 保留低频，去掉高频 | 墨镜——只让柔和的光通过，挡住刺眼的强光 |
| **高通（HPF）** | 保留高频，去掉低频 | 高音喇叭——只让高音通过，挡住低音 |
| **带通（BPF）** | 保留某一频段，去掉其他 | 收音机选台——只让特定电台的频率通过 |
| **带阻（BSF）** | 去掉某一频段，保留其他 | 陷波器——专门去掉50Hz工频噪声 |
| **全通（APF）** | 所有频率都通过，但改变相位 | 相位校正器——不改变幅度，只调整相位 |

### 滤波器的技术指标

设计滤波器时，需要明确以下指标：

| 指标 | 含义 | 说明 |
|---|---|---|
| **通带（Passband）** | 需要保留的频率范围 | 通带内信号尽量不衰减 |
| **阻带（Stopband）** | 需要去掉的频率范围 | 阻带内信号尽量衰减 |
| **截止频率（Cutoff）** | 通带和阻带的分界点 | 通常定义为幅度下降到-3dB的频率 |
| **过渡带（Transition Band）** | 通带和阻带之间的区域 | 越窄越好，但需要更高的滤波器阶数 |
| **通带波纹（Passband Ripple）** | 通带内幅度的波动 | 越小越好 |
| **阻带衰减（Stopband Attenuation）** | 阻带内信号的衰减程度 | 越大越好，通常用dB表示 |

**生活类比**：滤波器就像筛子——通带是能通过筛孔的颗粒大小，阻带是被挡住的颗粒，过渡带是筛孔边缘的模糊地带，波纹是筛孔大小的不均匀性，衰减是挡住颗粒的比例。

### FIR vs IIR

这是数字滤波器的两大类别：

| 对比维度 | FIR（有限冲激响应） | IIR（无限冲激响应） |
|---|---|---|
| 冲激响应长度 | 有限（N个样本） | 无限（理论上） |
| 实现方式 | 非递归（只有前馈） | 递归（有反馈） |
| 稳定性 | 绝对稳定 | 可能不稳定 |
| 线性相位 | 可以实现（对称系数） | 难以实现 |
| 阶数 | 通常较高（需要更多系数） | 通常较低（更少系数） |
| 计算量 | 较大 | 较小 |
| 设计方法 | 简单（窗函数法、频率采样法） | 较复杂（双线性变换、模拟原型） |
| 有限字长效应 | 较小 | 较大（可能产生极限环） |
| 典型应用 | 音频处理、图像处理、数据通信 | 控制、通信、实时嵌入式 |

**一句话总结**：FIR设计简单、稳定、线性相位，但阶数高、计算量大；IIR阶数低、计算量小，但设计复杂、可能不稳定、相位非线性。

> 这篇我们讲FIR，下一篇讲IIR。

## 二、移动平均滤波器：最简单的FIR

### 原理

移动平均（Moving Average）是最简单的FIR滤波器，输出等于最近N个输入的平均值：

$$
y[n] = \frac{1}{N} \sum_{k=0}^{N-1} x[n-k]
$$

它的冲激响应是N个常数：
$$
h[n] = \begin{cases} 1/N, & 0 \le n < N \\ 0, & \text{其他} \end{cases}
$$

### 频率响应

移动平均是一个低通滤波器——它能平滑信号、去除高频噪声，但也会使信号的快速变化（如边沿、脉冲）变缓。

它的频率响应是sinc函数的形状：
- 主瓣：低频通过
- 旁瓣：高频有周期性的衰减峰值（纹波）
- 第一个零点在 $f = f_s/N$

### 优缺点

| 优点 | 缺点 |
|---|---|
| 极其简单，容易理解和实现 | 阻带衰减只有约21dB，不够大 |
| 计算量小（可以用递推实现） | 通带有波纹，不够平坦 |
| 线性相位 | 过渡带较宽 |
| 绝对稳定 | 不适合要求高的应用 |

**生活类比**：移动平均就像用手指抹开画上的颜料——能把粗糙的颗粒（噪声）抹平滑，但也会把清晰的线条（信号边沿）抹模糊。

### 递推实现（优化计算）

直接计算移动平均需要N次加法和1次乘法。但可以用递推公式，每次只需要1次加法、1次减法和1次乘法：

$$
y[n] = y[n-1] + \frac{x[n] - x[n-N]}{N}
$$

```c
// 移动平均滤波器（递推实现）
typedef struct {
    double *buffer;  // 输入缓冲
    int N;           // 平均点数
    int index;       // 当前索引
    double sum;      // 当前和
} MovingAverage;

double moving_average(MovingAverage *ma, double x) {
    ma->sum -= ma->buffer[ma->index];  // 减去最旧的样本
    ma->sum += x;                        // 加上新样本
    ma->buffer[ma->index] = x;          // 存入缓冲
    ma->index = (ma->index + 1) % ma->N; // 循环索引
    return ma->sum / ma->N;             // 返回平均值
}
```

## 三、窗函数sinc滤波器：标准FIR设计方法

移动平均太简单，性能不够好。要设计高性能的FIR滤波器，最常用的方法是**窗函数sinc法（Windowed-Sinc）**。

### 理想低通滤波器的冲激响应

理想低通滤波器的频率响应是：通带内幅度为1，阻带内幅度为0，过渡带宽度为0。

对这个理想频率响应做逆傅里叶变换，得到冲激响应：

$$
h[n] = \frac{\sin(2\pi f_c n)}{n\pi} = 2f_c \cdot \text{sinc}(2f_c n)
$$

其中$f_c$是截止频率（归一化频率，0到0.5）。

这就是**sinc函数**——它是理想低通滤波器的冲激响应。

> "Taking the Inverse Fourier Transform of this ideal frequency response produces the ideal filter kernel (impulse response)... this curve is of the general form: sin(x)/x, called the sinc function."
>
> ——第16章，第285页

翻译：对这个理想频率响应做逆傅里叶变换，产生理想滤波器核（冲激响应）……这条曲线的一般形式是sin(x)/x，称为sinc函数。

### 为什么需要加窗？

理想sinc滤波器有两个问题：
1. **无限长**：sinc函数从负无穷到正无穷，无法直接实现
2. **非因果**：sinc函数在n<0时也有值，意味着输出依赖未来的输入，物理上不可实现

解决方法是：**把sinc函数截断（加窗），并向右平移使其因果。**

但直接截断（矩形窗）会导致**吉布斯现象（Gibbs Phenomenon）**——频率响应出现约9%的过冲和振荡，阻带衰减只有约21dB。

为了改善这个问题，我们不用矩形窗，而是用**平滑的窗函数**——窗函数的两端逐渐衰减到0，而不是突然截断。

### 窗函数法的步骤

设计一个窗函数sinc低通滤波器的步骤：

1. **选择截止频率**$f_c$和滤波器长度$M$（系数个数，通常是奇数）
2. **生成sinc函数**：$h[i] = \frac{\sin(2\pi f_c (i - M/2))}{(i - M/2)\pi}$，其中$i=0,1,...,M-1$
3. **加窗**：$h[i] = h[i] \cdot w[i]$，其中$w[i]$是窗函数
4. **归一化**：把所有系数相加，然后每个系数除以总和，确保通带增益为1

**生活类比**：窗函数法就像修剪盆景——理想sinc是一棵无限大的树（理想滤波器），你用剪刀（窗函数）把它剪成合适的大小（有限长）。剪刀的形状（窗函数类型）决定了修剪后树的美观程度（滤波器性能）。

### 设计公式（低通滤波器）

$$
h[i] = w[i] \cdot \frac{\sin(2\pi f_c (i - M/2))}{(i - M/2)\pi}
$$

其中：
- $M$：滤波器长度（系数个数，奇数）
- $f_c$：截止频率（归一化，0到0.5）
- $w[i]$：窗函数
- $i=0,1,...,M-1$

特殊情况：当$i = M/2$时，分母为0，此时$h[M/2] = 2f_c$（sinc函数在0点的极限）。

### 其他类型滤波器

用sinc函数可以设计各种类型的滤波器：

| 类型 | 方法 |
|---|---|
| **低通** | 直接用sinc函数 |
| **高通** | 低通滤波器的频谱反转：$h_{hp}[i] = \delta[i] - h_{lp}[i]$ |
| **带通** | 两个低通相减：$h_{bp}[i] = h_{lp2}[i] - h_{lp1}[i]$（$f_{c2} > f_{c1}$） |
| **带阻** | 全通减去带通：$h_{bs}[i] = \delta[i] - h_{bp}[i]$ |

## 四、常见窗函数对比

不同的窗函数有不同的性能特点，选择窗函数是在**过渡带宽度**和**阻带衰减**之间做权衡。

| 窗函数 | 阻带衰减 | 过渡带宽度 | 通带波纹 | 特点 |
|---|---|---|---|---|
| **矩形（Rectangular）** | 21 dB | 最窄（1.8π/M） | 0.74 dB | 直接截断，吉布斯现象严重 |
| **汉宁（Hanning）** | 44 dB | 中等（3.1π/M） | 0.02 dB | 余弦平方，常用 |
| **汉明（Hamming）** | 53 dB | 中等（3.3π/M） | 0.02 dB | 优化的余弦，最常用 |
| **布莱克曼（Blackman）** | 74 dB | 较宽（5.5π/M） | 0.0003 dB | 三项余弦，高阻带衰减 |
| **凯撒（Kaiser）** | 可调 | 可调 | 可调 | 参数可调，灵活 |

**选择建议**：
- 一般应用用**汉明窗**（综合性能好）
- 需要高阻带衰减用**布莱克曼窗**
- 需要窄过渡带用**矩形窗**（但波纹大）
- 需要灵活控制用**凯撒窗**

**生活类比**：窗函数就像不同形状的剪刀——矩形窗是菜刀，剪得快但边缘粗糙（过渡带窄但阻带衰减小）；布莱克曼窗是修枝剪，剪得精细但剪得慢（阻带衰减大但过渡带宽）。

## 五、自定义滤波器：频率采样法

窗函数sinc法只能设计标准的低通、高通、带通、带阻滤波器。如果需要**任意形状的频率响应**，可以用**频率采样法（Frequency Sampling Method）**。

### 原理

频率采样法的思路很直接：
1. 指定想要的频率响应$H[k]$（在N个频率点上的值）
2. 对$H[k]$做逆DFT，得到冲激响应$h[n]$
3. 如果需要，加窗平滑

### 步骤

1. **确定滤波器长度**$N$
2. **指定频率响应**：在$k=0,1,...,N/2$（正频率）上指定幅度和相位
3. **构造完整DFT**：利用共轭对称性填充负频率部分
4. **逆DFT**：得到冲激响应$h[n]$
5. **加窗（可选）**：如果需要改善性能，可以加窗

**生活类比**：频率采样法就像定制衣服——你告诉裁缝你想要的衣服形状（频率响应），裁缝用布料（逆DFT）做出衣服（冲激响应）。窗函数sinc法是买现成的标准尺码，频率采样法是量身定制。

## 六、FFT卷积：快速实现FIR滤波

直接卷积的时间复杂度是O(N×M)，当信号很长（N=10000）、滤波器阶数很高（M=1024）时，计算量很大。

根据卷积定理：**时域卷积 = 频域乘积**。所以可以用FFT实现快速卷积：

1. 对输入信号$x[n]$做FFT，得到$X[k]$
2. 对滤波器冲激响应$h[n]$做FFT，得到$H[k]$（可以预先算好）
3. 频域相乘：$Y[k] = X[k] \cdot H[k]$
4. 逆FFT：得到输出$y[n]$

时间复杂度是O((N+M)log(N+M))，比直接卷积快得多。

### 重叠相加法（Overlap-Add）

当信号是无限长（如实时音频流）时，不能一次做FFT，需要分块处理：

1. 把输入信号分成固定长度的块（如每块1024点）
2. 每块和滤波器做FFT卷积（块长度+滤波器长度-1）
3. 相邻块的输出有重叠，把重叠部分相加

这就是**重叠相加法**，是实时FIR滤波的标准实现方法。

## 七、完整实例：设计一个音频低通滤波器

假设我们要设计一个音频低通滤波器：
- 采样率：44100 Hz
- 截止频率：1000 Hz
- 阻带衰减：>50 dB
- 用汉明窗

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数
fs = 44100      # 采样率
fc = 1000       # 截止频率
M = 101         # 滤波器长度（奇数）
fc_norm = fc / fs  # 归一化截止频率

# 1. 生成sinc函数
n = np.arange(M)
h = np.sinc(2 * fc_norm * (n - M/2)) * (2 * fc_norm)

# 2. 加汉明窗
window = np.hamming(M)
h = h * window

# 3. 归一化（通带增益为1）
h = h / np.sum(h)

# 4. 计算频率响应
w, H = np.freqz(h, 1, worN=2048, fs=fs)

# 5. 打印性能指标
print(f"滤波器长度: {M}")
print(f"截止频率: {fc} Hz")
print(f"通带波纹: {20*np.log10(np.max(np.abs(H[:int(fc*len(w)/fs)]))):.2f} dB")
print(f"阻带衰减: {20*np.log10(np.min(np.abs(H[int(2*fc*len(w)/fs):]))):.2f} dB")

# 输出：
# 滤波器长度: 101
# 截止频率: 1000 Hz
# 通带波纹: 0.02 dB
# 阻带衰减: -53.2 dB
```

这个101阶的FIR低通滤波器，用汉明窗，实现了约53dB的阻带衰减和0.02dB的通带波纹，完全满足大多数音频应用的需求。

## 八、常见误区与坑

| 误区 | 正确理解 |
|---|---|
| "FIR滤波器阶数越高越好" | 阶数越高，过渡带越窄、阻带衰减越大，但计算量也越大、延迟也越大；根据需求选择合适的阶数 |
| "窗函数随便选一个就行" | 窗函数决定了滤波器的性能（阻带衰减、过渡带、波纹），需要根据需求选择 |
| "截止频率就是-3dB点" | 窗函数法的截止频率定义是理想低通的截止频率，实际-3dB点可能略有偏移 |
| "FIR滤波器一定是线性相位" | 只有系数对称的FIR滤波器才有线性相位；非对称FIR没有线性相位 |
| "直接卷积太慢，都要用FFT卷积" | 当滤波器阶数很低（如<32）时，直接卷积比FFT卷积更快，因为FFT有额外开销 |
| "加窗只会有好处" | 加窗能增加阻带衰减，但会加宽过渡带；是一种权衡 |
| "sinc函数的中心值是0" | sinc函数在0点的极限是1（sin(x)/x在x→0时极限为1），不是0 |
| "高通滤波器就是低通反过来" | 高通可以通过频谱反转从低通得到，但不是简单的系数反转 |
| "FIR滤波器不会有稳定性问题" | FIR确实绝对稳定（因为没有反馈），但有限字长效应仍可能导致性能下降 |

## 小结

这篇是【DSP系列】核心主题4，我们搞懂了FIR数字滤波器的设计：

1. **滤波器基础**：两个用途（信号分离、信号恢复）、五种类型（低通/高通/带通/带阻/全通）、技术指标（通带/阻带/过渡带/波纹/衰减）
2. **FIR vs IIR**：FIR设计简单、绝对稳定、线性相位，但阶数高、计算量大；IIR相反
3. **移动平均**：最简单的FIR，平滑信号，阻带衰减只有21dB，适合简单应用
4. **窗函数sinc法**：标准FIR设计方法——生成sinc函数→加窗→归一化；汉明窗最常用
5. **窗函数对比**：矩形（过渡带窄但衰减小）、汉宁/汉明（中等）、布莱克曼（衰减大但过渡带宽）、凯撒（可调）
6. **频率采样法**：设计任意形状频率响应的方法
7. **FFT卷积**：用频域乘积实现快速卷积，重叠相加法处理无限长信号

**最重要的三句话**：
- **窗函数sinc法是FIR滤波器设计的标准方法**——sinc是理想低通的冲激响应，加窗使其有限长且因果
- **窗函数的选择是过渡带和阻带衰减的权衡**——汉明窗是大多数应用的好选择
- **FIR滤波器绝对稳定且可以实现线性相位**——这是它相比IIR的最大优势

下一篇（第8篇），我们讲**IIR递归滤波器与切比雪夫**——IIR用更少的阶数达到和FIR相同的性能，但设计更复杂，还有稳定性问题。切比雪夫、巴特沃斯、椭圆滤波器，这些经典IIR设计方法是怎么回事？FIR和IIR到底该怎么选？这些问题的答案都在下一篇。
