场景一

函数返回多个值，某些值就只能通过指针返回传入的参数实际上是需要保存带回的结果的变量
例子：

#include
 void MinMax(int num[], int lon, int *min, int *max)//声明函数（建议函数写好之后再声明，或者直接将需要的函数写在主函数前面,可以免去声明，然后免去很多麻烦
int main(void){
 int num[]={1,9,3,8,12,23,43,33,6,10};
 int min, max;
 MinMax(num, sizeof(num)/sizeof(num[0]),&min, &max);
 printf("MIn=%d,\nMax=%d\n",min, max);
 return 0;}
//下面的指针代表数组，简而言之，数组就是特殊的指针
void MinMax(int *num, int lon, int *min, int *max)//函数部分，将数组传入函数中要注意：1.传入时只将数组名带入,2.接收数组时要用数组接收
 {
 int i;
 *min=*max=num[0];
 for(i=0; i<=lon; i++){
 if(num[i]<*min){
 *min=num[i];
 }
 if(num[i]>*max){
 *max=num[i];
 }
 }
 }

场景二

函数返回运算状态，结果通过指针返回
常用的套路是让函数返回特殊的不属于有效范围内的值来表示出错：
-1或0（在文件操作会看到大量的例子）
但是当任何数值都是有效的可能结果时，就得分开返回了
后续的语言（C++，Java）采用了异常机制来解决这个问题

常见错误

定义了指针变量，还没指向任何变量就开始使用指针
