## 开篇：为什么一串圣诞灯坏了一个，整串都不亮？

圣诞节快到了，你挂了一串漂亮的彩灯，通电后五彩斑斓。但第二天，你发现整串灯都不亮了。检查了半天，发现只是其中一个灯泡坏了——为什么一个灯泡坏了，整串都不亮呢？

答案是：这串灯是**串联**的。电流从电源正极出来，依次流过每一个灯泡，最后回到负极。一个灯泡坏了（灯丝断了），整个电路就断了，电流流不过去，所有灯都不亮了。

如果你把这些灯改成**并联**——每个灯泡都直接接在电源两端——那一个灯泡坏了，其他灯照样亮，因为电流有其他路可以走。

串联和并联是电路最基本的两种连接方式，理解了它们，再加上欧姆定律和基尔霍夫定律，你就能分析80%以上的简单电路。这篇文章我们就来深入学习这"三板斧"。

## 一、欧姆定律：电路分析的"牛顿第一定律"

### 欧姆定律是什么

欧姆定律是电路分析最基础的公式，由德国物理学家格奥尔格·欧姆在1827年提出。它描述了电压、电流、电阻三者之间的关系：

$$I = \frac{V}{R}$$

电流等于电压除以电阻。也可以写成：
$$V = I \times R$$
$$R = \frac{V}{I}$$

> 作者说："This is called Ohm's law, and is named in honor of Georg Ohm... It is, along with Kirchhoff's laws, the foundation of DC electrical circuits."（第78页，3.5 Ohm's Law）
>
> 翻译：这就是欧姆定律，以格奥尔格·欧姆命名……它和基尔霍夫定律一起，构成了直流电路的基础。

**生活类比**：欧姆定律就像水管里的水流——水流（电流）= 水压（电压）÷ 水管阻力（电阻）。水压越大、水管越粗，水流越大；水压越小、水管越细，水流越小。

### 欧姆定律的适用范围

这是一个非常重要但经常被忽略的点：**欧姆定律只适用于线性电阻（如金属电阻），不适用于非线性元件（如二极管、三极管、热敏电阻）。**

什么是线性电阻？就是电压和电流成正比关系——电压加倍，电流也加倍。在V-I图上，线性电阻是一条过原点的直线，斜率就是电阻值。

但二极管就不一样了——正向电压低于0.7V时几乎没有电流，超过0.7V后电流急剧增加。在V-I图上是一条曲线，不是直线，所以不能用简单的欧姆定律$I=V/R$来描述，需要用更复杂的模型。

**生活类比**：线性电阻就像一个标准的水龙头——拧开的角度和出水量成正比。非线性元件就像一个特殊的阀门——拧到某个位置之前几乎不出水，超过那个位置后出水量突然暴增。

### 值得思考的点

- 欧姆定律是实验发现的，不是理论推导的——欧姆通过大量实验发现了电压和电流的正比关系
- 超导体在特定温度下电阻为零，这时候欧姆定律就不适用了（分母为零）
- 金属的电阻随温度变化，所以严格来说，即使是金属电阻，也只有在温度恒定时才是"线性"的

## 二、基尔霍夫电压定律（KVL）：绕一圈回到原点

### KVL是什么

基尔霍夫电压定律（Kirchhoff's Voltage Law，KVL）由德国物理学家古斯塔夫·基尔霍夫在1845年提出。它说的是：**在任何一个闭合回路中，所有电压升的和等于所有电压降的和，或者说，所有电压的代数和为零。**

> 作者说："this law states that the sum of voltage rises and voltage drops around a series loop must equal zero."（第82页，3.6 Kirchhoff's Voltage Law）
>
> 翻译：这个定律说，串联回路中所有电压升和电压降的和必须等于零。

用公式表示：
$$\sum V = 0$$

**生活类比**：KVL就像爬山——你从山脚出发，往上爬了100米（电压升），又往下走了30米（电压降），再往上爬了50米（电压升），最后往下走了120米（电压降），回到了山脚。所有高度变化的和是零：+100 - 30 + 50 - 120 = 0。

### 电压分压规则（VDR）

KVL的一个直接推论是电压分压规则（Voltage Divider Rule，VDR）。在串联电路中，电流处处相等，所以每个电阻上的电压降和它的电阻值成正比：

$$V_n = V_{total} \times \frac{R_n}{R_{total}}$$

> 作者说："An outgrowth of KVL is the voltage divider rule (VDR). In a series connection, the current is the same through each component. Thus, the voltage drops in a series..."（第83页，The Voltage Divider Rule）

**生活类比**：这就像三个人分一笔钱——按出资比例分，出得多的分得多。串联电路中，电阻大的分到的电压多，电阻小的分到的电压少。

分压电路是电子工程中最常用的电路之一——电位器调压、传感器信号调理、ADC输入范围调整，都用的是分压原理。

## 三、基尔霍夫电流定律（KCL）：流进来的等于流出去的

### KCL是什么

基尔霍夫电流定律（Kirchhoff's Current Law，KCL）说的是：**在任何一个节点（电路中三条或以上导线的连接点），流入节点的电流之和等于流出节点的电流之和，或者说，所有电流的代数和为零。**

$$\sum I_{in} = \sum I_{out}$$
$$\sum I = 0$$

**生活类比**：KCL就像水管的分叉口——流进分叉口的水量等于流出各个支管的水量之和。水不会凭空产生，也不会凭空消失，电流也是一样（电荷守恒）。

### 电流分流规则（CDR）

KCL的一个直接推论是电流分流规则（Current Divider Rule，CDR）。在并联电路中，电压处处相等，所以每个电阻上的电流和它的电阻值成反比：

$$I_n = I_{total} \times \frac{R_{other}}{R_n + R_{other}}$$

（两个电阻并联时，流过R1的电流 = 总电流 × R2/(R1+R2)）

**生活类比**：这就像两条并排的水管——粗的水管（电阻小）流的水多，细的水管（电阻大）流的水少。并联电路中，电阻小的支路电流大，电阻大的支路电流小。

## 四、串联电路：电流处处相等

### 串联电路的特点

串联电路就是元件一个接一个地连起来，像一串糖葫芦。电流只有一条路可以走，所以：

| 特点 | 公式 | 说明 |
|---|---|---|
| 电流处处相等 | $I_1 = I_2 = ... = I_n = I$ | 只有一条路，电流处处相同 |
| 总电压等于各电压之和 | $V_{total} = V_1 + V_2 + ... + V_n$ | KVL |
| 总电阻等于各电阻之和 | $R_{total} = R_1 + R_2 + ... + R_n$ | 电阻串联相加 |
| 电压和电阻成正比 | $V_n / R_n = I$（常数） | 分压规则 |

**生活类比**：串联就像一条单车道的公路——所有车都必须走同一条路，所以每个路段的车流量（电流）都一样；但每个路段的限速（电阻）不同，所以每个路段的行驶时间（电压降）不同。

### 串联电路的优缺点

**优点**：
- 结构简单，一个开关就能控制所有元件
- 电流处处相等，适合需要恒流的场合（如LED串联）
- 可以用分压电路获得不同的电压

**缺点**：
- 一个元件坏了（断路），整个电路都不工作——这就是圣诞灯的问题
- 总电压被分摊，每个元件分到的电压可能不够
- 总电阻是各电阻之和，电阻越大电流越小

### 完整实例：串联LED电路

**问题**：你有一个9V电池，一个红色LED（正向电压2V，工作电流20mA），需要串联一个限流电阻。求电阻值和电阻消耗的功率。

**解**：

1. 电阻上的电压降：$V_R = V_{battery} - V_{LED} = 9V - 2V = 7V$
2. 串联电路电流处处相等，所以电阻上的电流也是20mA = 0.02A
3. 电阻值：$R = V_R / I = 7V / 0.02A = 350Ω$
4. 选标准电阻值：330Ω或360Ω（E24系列没有350Ω，选最接近的330Ω）
5. 实际电流：$I = 7V / 330Ω = 21.2mA$（略大于20mA，可接受）
6. 电阻消耗的功率：$P = V_R \times I = 7V \times 0.0212A = 0.148W$
7. 选电阻额定功率：0.25W（1/4W）的电阻即可，留有余量

> 作者在第3章有类似的例题："A 9 volt battery is used in series to power a 40 Ω resistor..."（第79页，3.5 Ohm's Law 的例题）

## 五、并联电路：电压处处相等

### 并联电路的特点

并联电路就是所有元件的一端连在一起，另一端也连在一起，像梯子的横档。每个元件都直接接在电源两端，所以：

| 特点 | 公式 | 说明 |
|---|---|---|
| 电压处处相等 | $V_1 = V_2 = ... = V_n = V$ | 每个元件都直接接电源 |
| 总电流等于各电流之和 | $I_{total} = I_1 + I_2 + ... + I_n$ | KCL |
| 总电阻的倒数等于各倒数之和 | $1/R_{total} = 1/R_1 + 1/R_2 + ... + 1/R_n$ | 电阻并联倒数相加 |
| 电流和电阻成反比 | $I_n \times R_n = V$（常数） | 分流规则 |

**两个电阻并联的简化公式**：
$$R_{total} = \frac{R_1 \times R_2}{R_1 + R_2}$$

**生活类比**：并联就像多车道的公路——每条车道都可以独立通行，所以每条车道的车速限制（电压）都一样；但车流量（电流）可以分配到不同车道，总车流量是各车道之和。

### 并联电路的优缺点

**优点**：
- 一个元件坏了（断路），其他元件照常工作——家里的电器都是并联的
- 每个元件都获得完整的电源电压，不需要分压
- 可以独立控制每个支路的开关

**缺点**：
- 总电流是各支路之和，电源需要提供更大的电流
- 总电阻比最小的支路电阻还小——两个电阻并联，等效电阻比最小的那个还小
- 短路一个支路会导致整个电路短路（电流无穷大，烧保险丝）

### 为什么并联电阻比最小的还小？

这是初学者经常困惑的问题。直觉上，两个电阻加起来应该更大，但并联反而更小。

**解释**：并联相当于增加了导体的横截面积——两个相同的电阻并联，就像把两根相同的导线并在一起，横截面积加倍，电阻减半。横截面积越大，电阻越小，所以并联电阻比任何一个支路电阻都小。

**生活类比**：这就像超市结账——开一个收银台（一个电阻），排队的人（电流）只能一个一个过；再开一个收银台（并联一个电阻），排队的人可以分成两队，整体通过速度（总电流）加倍，等效"阻力"（等效电阻）减半。

## 六、串并联混合电路：逐步化简

实际电路几乎都是串联和并联的混合。分析方法是**从内到外，逐步化简**：

1. 先找最内层的串联或并联组合，计算等效电阻
2. 用等效电阻替换原来的组合，得到更简单的电路
3. 重复步骤1-2，直到电路化简为一个单一的等效电阻
4. 计算总电流，然后从外到内，逐步计算每个元件的电压和电流

**生活类比**：这就像解一个嵌套的数学公式——先算最里面的括号，再算外面的，一层一层往外算。

### 完整实例：串并联混合电路

**问题**：电路如下：R1=10Ω和R2=20Ω串联，然后和R3=30Ω并联，最后接在12V电源上。求总电流、各电阻的电压和电流。

**解**：

1. **化简R1和R2的串联**：
   $R_{12} = R1 + R2 = 10 + 20 = 30Ω$

2. **化简R12和R3的并联**：
   $R_{total} = (R_{12} \times R3) / (R_{12} + R3) = (30 \times 30) / (30 + 30) = 900 / 60 = 15Ω$

3. **计算总电流**：
   $I_{total} = V / R_{total} = 12V / 15Ω = 0.8A$

4. **计算各支路电流（分流公式）**：
   - R12支路电流：$I_{12} = I_{total} \times R3 / (R_{12} + R3) = 0.8 \times 30 / 60 = 0.4A$
   - R3支路电流：$I_3 = I_{total} \times R_{12} / (R_{12} + R3) = 0.8 \times 30 / 60 = 0.4A$
   - 验证：$I_{12} + I_3 = 0.4 + 0.4 = 0.8A = I_{total}$ ✓

5. **计算各电阻电压**：
   - R3电压：$V_3 = I_3 \times R3 = 0.4A \times 30Ω = 12V$（并联支路电压等于电源电压）
   - R12支路总电压：也是12V（并联）
   - R1电压：$V_1 = I_{12} \times R1 = 0.4A \times 10Ω = 4V$
   - R2电压：$V_2 = I_{12} \times R2 = 0.4A \times 20Ω = 8V$
   - 验证：$V_1 + V_2 = 4 + 8 = 12V = V_{12}$ ✓

6. **功率验证**：
   - R1功率：$P_1 = V_1 \times I_{12} = 4 \times 0.4 = 1.6W$
   - R2功率：$P_2 = 8 \times 0.4 = 3.2W$
   - R3功率：$P_3 = 12 \times 0.4 = 4.8W$
   - 总功率：$P_{total} = 1.6 + 3.2 + 4.8 = 9.6W$
   - 电源功率：$P = V \times I = 12 \times 0.8 = 9.6W$ ✓

## 七、电位器与分压电路

电位器（Potentiometer）是一种可调电阻，有三个引脚——两端是固定电阻，中间是滑动端。转动旋钮时，滑动端的位置改变，从而改变上下两部分的电阻比值。

电位器最常见的用途是**分压电路**：

$$V_{out} = V_{in} \times \frac{R_{lower}}{R_{total}}$$

转动旋钮改变$R_{lower}$，就能连续调节输出电压。

**生活类比**：电位器就像一个可以调节位置的水坝——水坝把河流分成上下两段，移动水坝的位置就能改变上下两段的水位差。

**常见应用**：
- 音量调节旋钮（音频信号分压）
- 亮度调节（LED电流调节）
- 传感器校准（微调基准电压）
- 模拟输入（旋钮位置转成电压，送给ADC）

**注意事项**：
- 电位器有功率限制，不能通过太大的电流
- 电位器的分辨率有限（碳膜电位器通常是连续的，数字电位器是离散的）
- 电位器有寿命限制（转动次数有限，通常1万到10万次）

## 八、保险丝与断路器：过流保护

保险丝（Fuse）和断路器（Circuit Breaker）是电路中的"安全卫士"——当电流超过额定值时，它们会断开电路，防止元件损坏或火灾。

> 作者在第4章专门有一节讲"Current Limiting: Fuses and Circuit Breakers"（电流限制：保险丝和断路器）。（第125页，4.6）

### 保险丝

保险丝是一根特殊的金属丝，当电流超过额定值时，金属丝发热熔化，断开电路。

**特点**：
- 一次性使用——熔断后必须更换
- 响应速度快（毫秒级）
- 结构简单，成本低
- 有不同的额定电流和熔断特性（快熔/慢熔）

**保险丝额定电流怎么选**：
- 正常工作电流的1.5-2倍
- 要考虑浪涌电流（如电机启动、电容充电）——有浪涌时选慢熔保险丝
- 要考虑环境温度——高温下保险丝的额定电流会降低

### 断路器

断路器是一种可重复使用的过流保护装置，当电流超过额定值时，内部的电磁机构或双金属片触发机构断开电路。排除故障后，可以手动复位。

**特点**：
- 可重复使用——跳闸后可以复位
- 有不同的脱扣特性（B/C/D型，对应不同的瞬时脱扣电流倍数）
- 成本比保险丝高，但长期使用更经济
- 常用于建筑配电、工业设备

**生活类比**：保险丝就像一次性的安全气囊——触发一次就报废，必须更换；断路器就像可复位的安全开关——触发后可以手动复位，重复使用。

### 为什么不能用铜丝代替保险丝？

这是一个非常危险的误区。铜丝的熔点很高，电流超过额定值时不会熔断，会导致：
- 电线过热，绝缘层熔化，引发火灾
- 用电设备过流损坏
- 可能导致触电危险

**记住**：保险丝必须用规定额定值的专用保险丝，绝对不能用铜丝、铁丝等代替。

## 九、常见误区与坑

| 误区 | 正确理解 |
|---|---|
| "串联电路总电阻等于各电阻之和，并联也是" | 串联电阻相加，并联电阻倒数相加。两个电阻并联：$R=(R1×R2)/(R1+R2)$ |
| "并联电阻的总电阻介于两个电阻之间" | 并联电阻比最小的那个还小——并联相当于增加横截面积 |
| "欧姆定律适用于所有元件" | 只适用于线性电阻（金属电阻），二极管、三极管等非线性元件不适用 |
| "串联电路中电阻大的电流小" | 串联电路电流处处相等，电阻大的电压降大，电流一样 |
| "并联电路中电阻大的电压小" | 并联电路电压处处相等，电阻大的电流小，电压一样 |
| "保险丝选越大越安全" | 保险丝选太大，过流时不熔断，起不到保护作用；选太小，正常工作时就熔断 |
| "电位器可以随便调，不会坏" | 电位器有功率限制，电流太大会烧坏；也有寿命限制，频繁调节会磨损 |
| "测电流时万用表并联在电路里" | 测电流必须串联，测电压才是并联。接错了会烧保险丝 |

## 小结

这篇文章我们学习了电路分析的"三板斧"：

1. **欧姆定律**：$I=V/R$，电路分析最基础的公式，只适用于线性电阻
2. **基尔霍夫电压定律（KVL）**：闭合回路电压和为零，推论是分压规则（VDR）
3. **基尔霍夫电流定律（KCL）**：节点电流和为零，推论是分流规则（CDR）

以及三种基本电路结构：

4. **串联电路**：电流处处相等，电压相加，电阻相加，一个坏了全不亮
5. **并联电路**：电压处处相等，电流相加，电阻倒数相加，一个坏了其他照常
6. **串并联混合**：从内到外逐步化简，先算等效电阻，再算总电流，最后从外到内算各元件参数

还有两个实用元件：

7. **电位器**：可调电阻，最常用于分压电路，连续调节输出电压
8. **保险丝/断路器**：过流保护，保险丝一次性使用，断路器可复位，绝对不能用铜丝代替保险丝

最重要的三句话：
- **串联电流相等，并联电压相等**——这是分析串并联电路的钥匙
- **欧姆定律只适用于线性电阻**——遇到非线性元件要用更复杂的模型
- **从内到外逐步化简**——分析复杂电路的通用方法

下一篇（第6篇），我们进入第三个核心主题——复杂电路的系统分析方法：叠加定理、戴维南定理、诺顿定理、最大功率传输、节点分析、网孔分析、受控源。这些工具能让你应对更复杂的电路。
