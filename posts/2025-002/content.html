1. 数据类型对比

场景PythonC 语言

3. 关键差异示例
(1) 变量类型灵活性
# Python：动态类型
x = 42 # x 是 int
x = "hello" # x 变为 str

// C：静态类型
int x = 42; 
x = "hello"; // 编译错误：类型不兼容
(2) 字符串处理
# Python：字符串是对象，支持灵活操作
s = "123"
num = int(s) # 直接转换

// C：字符串是字符数组，需手动处理
#include 
char s[] = "123";
int num = atoi(s); // 需要库函数
(3) 容器类型
# Python：内置高级容器
lst = [1, 2, 3]
d = {"key": "value"}

// C：需手动实现或依赖结构体
int arr[3] = {1, 2, 3}; // 固定大小数组
struct Dict { char* key; int value; }; // 自定义字典结构
(4) 指针与内存管理
# Python：无显式指针，自动内存管理
a = [1, 2, 3]
b = a # b 是 a 的引用

// C：显式指针和内存操作
int* arr = malloc(3 * sizeof(int)); // 手动分配内存
free(arr); // 手动释放

>5. 选择建议
  • 用 Python：快速开发、数据处理、原型验证、高可读性需求。
  • 用 C：对性能要求极高、需要直接操作硬件、内存受限的场景（如嵌入式系统）。

两种语言在数据类型和转换上的差异，本质是设计哲学的不同：Python 追求开发效率，C 追求执行效率。

Python 中常见的数据类型主要包括以下几种基础类型，以及它们之间的转换方法：

一、Python 基础数据类型
  1. 整数（int）
    • 例如：42, -3
  2. 浮点数（float）
    • 例如：3.14, -0.5
  3. 字符串（str）
    • 例如："hello", 'Python'
  4. 布尔值（bool）
    • 例如：True, False
  5. 列表（list）
    • 例如：[1, 2, 3], ["a", "b"]
  6. 元组（tuple）
    • 例如：(1, 2, 3), ("x", "y")
  7. 字典（dict）
    • 例如：{"name": "Alice", "age": 25}
  8. 集合（set）
    • 例如：{1, 2, 3}
  9. 空类型（NoneType）
    • 例如：None
二、数据类型之间的转换

以下是常见数据类型之间的显式转换方法及示例：

1. 数值类型转换

  • int → float

    num_int = 42
num_float = float(num_int) # 42.0

  • float → int

    num_float = 3.99
num_int = int(num_float) # 3（直接截断小数）

  • str → int/float

    s = "123"
num_int = int(s) # 123
num_float = float("3.14") # 3.14
2. 字符串与其他类型

  • int/float → str

    s = str(42) # "42"
s = str(3.14) # "3.14"

  • list/tuple → str

    lst = [1, 2, 3]
s = str(lst) # "[1, 2, 3]"

  • str → list

    s = "hello"
lst = list(s) # ['h', 'e', 'l', 'l', 'o']
3. 容器类型转换

  • list ↔ tuple

    my_list = [1, 2, 3]
my_tuple = tuple(my_list) # (1, 2, 3)

my_tuple = (4, 5, 6)
my_list = list(my_tuple) # [4, 5, 6]

  • list/tuple → set

    my_list = [1, 2, 2, 3]
my_set = set(my_list) # {1, 2, 3}（去重）

  • dict → list/tuple

    my_dict = {"a": 1, "b": 2}
keys = list(my_dict.keys()) # ["a", "b"]
values = tuple(my_dict.values()) # (1, 2)
items = list(my_dict.items()) # [('a', 1), ('b', 2)]

  • list → dict（需满足键值对结构）

    my_list = [("a", 1), ("b", 2)]
my_dict = dict(my_list) # {"a": 1, "b": 2}
4. 布尔转换
  • 其他类型 → bool
    bool(0) # False（数值0为False）
bool("") # False（空字符串为False）
bool([]) # False（空列表为False）
bool(None) # False
5. 其他转换
  • bytes ↔ str
    s = "hello"
bytes_data = s.encode("utf-8") # b'hello'
s_decoded = bytes_data.decode("utf-8") # "hello"
>三、注意事项

  1. 数据丢失

    • float → int 会截断小数部分。
    • str → int 要求字符串必须是数字格式（否则报错）。

  2. 隐式转换

    • 在运算中，Python 会自动转换类型，例如 3 + 4.5 会隐式转换为 float。

  3. 特殊转换

    • eval() 可以将字符串解析为 Python 对象，但存在安全风险，需谨慎使用。

通过灵活使用 int(), float(), str(), list(), tuple(), dict() 等函数，可以实现绝大多数数据类型转换需求。
