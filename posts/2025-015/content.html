GCC相关的小玩意

指令

gcc --help :Display help information
gcc input.c -o output.exe -Xlinker -Map=output.map:产生map文件

map文件

Archive member included to satisfy reference by file (symbol):这是一个包含在map文件中的信息，说明在编译程序时，由于某些符号被引用而需要包含的对象文件或库文件。该信息可用于检查编译过程中缺失的依赖项
Allocating common symbols(分配通用符号):在map文件中指定的是非初始化变量或多个文件中共享的变量，它们会在链接过程中被放置在一个特殊的区域中（通常称为BSS段），并被所有使用它们的模块共享。这些变量被分配在运行时，而不是在编译时分配内存。这个过程在常规应用程序中很常见，因为它允许多个源文件共享相同的数据，从而减少程序的总大小。
Discarded input sections(丢弃的输入段):Map中的Discarded input sections指的是在Map阶段输出键值对时被丢弃的部分输入数据。这些数据被丢弃的原因可能是不符合Map函数的输入数据格式要求（比如，数据类型错误、数据缺失等），或者是被过滤掉的无用数据（例如，行首和行尾的空格、注释等）。

递归式堆栈遍历伪代码

以下是使用递归方式获取调用堆栈的伪代码实现，最大递归深度为16层。这个实现抽象了不同平台的细节，专注于递归遍历的核心逻辑：

# 递归堆栈遍历伪代码
def walk_stack_recursive(fp: Pointer, depth: int, max_depth: int) -> List[Address]:
 """
 递归遍历调用堆栈
 :param fp: 当前帧指针
 :param depth: 当前递归深度
 :param max_depth: 最大允许深度
 :return: 返回地址列表（从当前函数到外层函数）
 """
 # 终止条件：达到最大深度或无效帧指针
 if depth >= max_depth or not fp or not is_valid_frame_pointer(fp):
 return []
 
 # 获取当前函数的返回地址
 return_address = read_return_address(fp)
 
 # 验证返回地址有效性
 if not is_valid_address(return_address):
 return []
 
 # 获取前一个帧指针（调用者的帧指针）
 prev_fp = read_previous_frame_pointer(fp)
 
 # 终止条件：无效前帧指针或循环引用
 if not prev_fp or prev_fp == fp or not is_valid_frame_pointer(prev_fp):
 return [return_address]
 
 # 递归获取调用者堆栈
 caller_stack = walk_stack_recursive(prev_fp, depth + 1, max_depth)
 
 # 将当前返回地址添加到结果列表
 return caller_stack + [return_address]

# 主入口函数
def get_call_stack(max_depth: int = 16) -> List[Address]:
 """
 获取调用堆栈
 :param max_depth: 最大堆栈深度
 :return: 返回地址列表（从外层到内层）
 """
 # 获取当前帧指针
 current_fp = get_frame_pointer()
 
 # 处理叶子函数特殊情况
 if is_leaf_function(current_fp):
 leaf_ra = get_leaf_return_address()
 if is_valid_address(leaf_ra):
 return [leaf_ra]
 
 # 启动递归遍历
 return walk_stack_recursive(current_fp, 0, max_depth)

 """从帧指针读取返回地址"""

def read_previous_frame_pointer(fp: Pointer) -> Pointer:
 """读取前一个帧指针"""
 return *fp # 前帧指针存储在fp[0]

def is_valid_frame_pointer(fp: Pointer) -> bool:
 """检查帧指针是否有效"""
 # 非空、对齐、在堆栈范围内
 return fp and is_aligned(fp) and in_stack_range(fp)

def is_valid_address(addr: Address) -> bool:
 """检查地址是否有效"""
 # 非空、对齐、在代码段范围内
 return addr and is_aligned(addr) and in_code_range(addr)
