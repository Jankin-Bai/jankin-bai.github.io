建仓

在已有的文件夹中生成一个Git仓库并将其新建到Gitee的步骤如下：

1. 创建一个本地Git仓库

  1. 打开终端或命令提示符，进入你想要创建Git仓库的文件夹：

    cd /path/to/your/folder

  2. 初始化Git仓库：

    git init
2. 添加和提交文件到本地仓库

  1. 添加文件到Git暂存区：

    git add .

  2. 提交文件到本地仓库：

    git commit -m "Initial commit"
3. 在Gitee上创建一个新的仓库

  1. 登录到你的Gitee账户。

  2. 点击右上角的“+”按钮，并选择“新建仓库”。

  3. 填写仓库名称、描述等信息，并点击“创建”按钮。

4. 将本地仓库连接到Gitee仓库

  1. 返回到终端或命令提示符，添加Gitee远程仓库地址。假设你的Gitee仓库地址为https://gitee.com/your-username/your-repo.git：

    git remote add origin https://gitee.com/your-username/your-repo.git

  2. 推送本地仓库的内容到Gitee远程仓库：

    git push -u origin master
5. 确认推送成功
  1. 打开Gitee并导航到你新建的仓库，检查仓库是否包含你本地仓库的文件和提交记录。

这样，你就成功地在已有的文件夹中生成了一个Git仓库并将其新建到Gitee。如果你之后有任何变更需要推送到Gitee，只需重复 git add .、git commit -m "your message" 和 git push 这些步骤。

当你在cmake中遇到"-Werror=all"时

"-Werror=all"的后果是编译走不过去。
用-Wno-error=xxx或许可以救你
如下例子


 list(APPEND compile_options "-ffunction-sections"
 "-fdata-sections"
 # warning-related flags
 "-Wall"
 "-Werror=all"
 "-Wno-error=missing-braces"
 "-Wno-error=unused-function"
 "-Wno-error=unused-variable"
 "-Wno-error=deprecated-declarations"
 "-Wextra"
 "-Wno-unused-parameter"
 "-Wno-sign-compare"
 # always generate debug symbols (even in release mode, these don't
 # go into the final binary so have no impact on size
 "-ggdb")
