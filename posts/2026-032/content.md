## 开篇：为什么手机充电器里有一个嗡嗡响的铁疙瘩？

你拆开一个手机充电器，里面有一个方方正正的铁疙瘩，通电时偶尔能听到轻微的"嗡嗡"声。这个铁疙瘩就是**变压器**——它把220V的交流电变成几伏的低压电，给手机充电。

变压器为什么能改变电压？它里面没有任何运动部件，怎么就能把电压变高或变低？答案是**电磁感应**——变化的电流产生变化的磁场，变化的磁场又在另一个线圈里感应出电压。通过两个线圈的匝数比不同，就能实现电压的变换。

这篇文章我们就来深入学习电磁感应的本质、磁路的分析方法（和电路类比），以及变压器的工作原理。

---

## 一、电磁感应：变化的磁场产生电压

### 法拉第电磁感应定律

1831年，英国科学家迈克尔·法拉第发现了电磁感应现象：当穿过导体回路的磁通量发生变化时，回路中会产生感应电动势（电压）。

> 作者说："Perhaps the most important observation regarding magnetic systems is Faraday's law of electromagnetic induction."（第325页，10.2 Electromagnetic Induction）
>
> 法拉第定律：如果导体被变化的磁力线切割，就会产生感应电动势。

用公式表示：

$$v = N \times \frac{d\Phi}{dt}$$

- v：感应电压（伏特）
- N：线圈匝数
- $\Phi$（Phi）：磁通量（韦伯，Wb）
- $d\Phi/dt$：磁通量的变化率

翻译成人话：**线圈中的感应电压等于匝数乘以磁通量的变化率。磁通量变化越快、匝数越多，感应电压越大。**

**生活类比**：这就像用线圈做的"发电机"——你拿着磁铁在线圈旁边快速移动（磁通量变化快），线圈里就会产生电压；移动得越快，电压越大。这就是发电机、麦克风、动圈耳机的工作原理。

### 楞次定律：感应电压的方向

俄国物理学家楞次在1834年发现了感应电压的方向规律：**感应电流产生的磁场总是阻碍原磁通量的变化。**

这就是为什么电感"讨厌"电流变化——电流变化产生变化的磁场，变化的磁场在电感自身线圈里感应出反向电压，阻碍电流的变化。这就是**自感**。

如果两个线圈靠得很近，一个线圈的电流变化产生的变化磁场会在另一个线圈里感应出电压——这就是**互感**，变压器就是利用互感工作的。

### 电磁感应的应用

| 应用 | 原理 |
|---|---|
| **发电机** | 线圈在磁场中旋转，磁通量变化产生电压 |
| **变压器** | 原边电流变化产生变化磁场，副边感应出电压 |
| **动圈麦克风** | 声音振动带动线圈在磁场中运动，感应出电压 |
| **动圈耳机/扬声器** | 变化的电流通过线圈，产生变化的磁场，和永久磁铁相互作用振动发声 |
| **感应充电/无线充电** | 发射线圈产生变化磁场，接收线圈感应出电压 |
| **金属探测器** | 线圈产生变化磁场，金属中感应出涡流，涡流又影响线圈的阻抗 |

## 二、磁路：和电路类比的分析方法

### 磁路的基本概念

磁路是磁通（磁力线）经过的闭合路径，通常由铁磁材料（铁芯）组成，因为铁磁材料的磁导率远高于空气，磁通会被"约束"在铁芯里，就像电流被约束在导线里一样。

> 作者说："Magnetic circuits include applications such as transformers and relays."（第329页，10.3 Magnetic Circuits）

### 磁路-电路类比

磁路和电路有非常完美的类比关系，学会了电路分析，磁路分析就很容易：

| 电路量 | 符号 | 单位 | 磁路量 | 符号 | 单位 |
|---|---|---|---|---|---|
| 电流 | I | 安培（A） | 磁通 | $\Phi$ | 韦伯（Wb） |
| 电压/电动势 | V/E | 伏特（V） | 磁动势 | F | 安培匝（At） |
| 电阻 | R | 欧姆（Ω） | 磁阻 | $\mathcal{R}$ | 安培匝/韦伯（At/Wb） |
| 电阻率 | $\rho$ | Ω·m | 磁阻率 | $1/\mu$ | — |
| 电导率 | $\sigma$ | S/m | 磁导率 | $\mu$ | H/m |
| 电场强度 | E | V/m | 磁场强度 | H | At/m |
| 电流密度 | J | A/m² | 磁通密度 | B | Wb/m²（特斯拉T） |

### 磁路的"欧姆定律"

$$\Phi = \frac{F}{\mathcal{R}}$$

磁通 = 磁动势 / 磁阻，和电路的 I = V/R 完全对应。

磁动势 F = N × I（线圈匝数 × 电流），就像电路中的电压源。

磁阻 $\mathcal{R} = l / (\mu A)$（磁路长度 / (磁导率 × 截面积)），和电路的 R = ρL/A 完全对应。

### 磁路的KVL和KCL

和电路一样，磁路也有"KVL"（闭合磁路的磁动势和等于磁压降和）和"KCL"（磁路节点的磁通和为零，即磁通连续性）。

所以你学过的电路分析方法（串联、并联、分压、分流、戴维南等）都可以直接套用到磁路分析中——只要把电路量换成对应的磁路量就行。

**生活类比**：磁路就像水管系统——磁动势是水泵，磁通是水流，磁阻是水管阻力，磁导率是水管的通畅程度。铁磁材料就像粗水管（磁阻小），空气就像细水管（磁阻大）。

### 铁磁材料的磁化曲线

铁磁材料（铁、钴、镍及其合金）的磁导率不是常数——它随磁场强度变化，有饱和现象：

- **线性区**：磁场强度较小时，磁通密度和磁场强度成正比，磁导率近似常数
- **饱和区**：磁场强度超过一定值后，磁通密度增加缓慢，磁导率急剧下降
- **磁滞**：磁通密度的变化滞后于磁场强度，形成磁滞回线，产生磁滞损耗

这就是变压器和电感有"饱和电流"的原因——电流太大导致铁芯饱和，电感值急剧下降。

**常见铁磁材料**：
- **硅钢片**：工频变压器、电机，低损耗，便宜
- **铁氧体**：高频变压器、开关电源、EMI滤波，高频损耗低
- **坡莫合金**：高精度互感器、磁屏蔽，高磁导率
- **非晶/纳米晶**：高频高效变压器，极低损耗，较贵

## 三、变压器：利用互感改变电压

### 变压器的基本结构

变压器由两个（或多个）线圈绕在同一个铁芯上组成：
- **原边（初级）线圈**：接输入电源，匝数N1
- **副边（次级）线圈**：接负载，匝数N2
- **铁芯**：提供低磁阻的磁路，把原边产生的磁通"引导"到副边

> 作者在第10章讲了"Transformers"（变压器），这是磁路最重要的应用之一。（第342页，10.4）

### 理想变压器的工作原理

理想变压器假设：
- 线圈电阻为零（无铜损）
- 铁芯磁导率无穷大（无励磁电流、无磁阻）
- 无漏感（所有磁通同时穿过原边和副边）
- 无铁芯损耗（无磁滞损耗和涡流损耗）
- 工作在交流下（直流不能通过变压器传递能量）

在理想变压器中，原边和副边的每匝线圈感应的电压相同（因为穿过每匝的磁通变化率相同），所以：

### 变压比

$$\frac{V_1}{V_2} = \frac{N_1}{N_2}$$

原边电压和副边电压之比等于匝数比。如果N2 > N1，副边电压高于原边，是**升压变压器**；如果N2 < N1，是**降压变压器**。

### 变流比

理想变压器不消耗能量（无损耗），所以输入功率等于输出功率：

$$V_1 I_1 = V_2 I_2$$

结合变压比，得到：

$$\frac{I_1}{I_2} = \frac{N_2}{N_1}$$

电流比和匝数比成反比——升压变压器电流变小，降压变压器电流变大。

### 阻抗变换

变压器还能变换阻抗。把副边的负载电阻RL"反射"到原边，等效电阻为：

$$R_{in} = \left(\frac{N_1}{N_2}\right)^2 \times R_L$$

这在射频电路中非常重要——通过变压器实现阻抗匹配，把负载阻抗变换到源内阻，实现最大功率传输。

**生活类比**：变压器就像汽车的变速箱——发动机转速高、扭矩小（高电压、小电流），通过变速箱变换后，车轮转速低、扭矩大（低电压、大电流）。匝数比就像齿轮比，决定了变换比例。

### 完整实例：变压器计算

**问题**：一个理想变压器，原边220V，匝数比N1:N2=10:1，副边接一个10Ω负载。求副边电压、副边电流、原边电流、原边等效输入电阻。

**解**：

1. **副边电压**：
   $V_2 = V_1 \times (N_2/N_1) = 220 \times (1/10) = 22V$

2. **副边电流**：
   $I_2 = V_2 / R_L = 22V / 10Ω = 2.2A$

3. **原边电流**：
   $I_1 = I_2 \times (N_2/N_1) = 2.2 \times (1/10) = 0.22A$

4. **验证功率**：
   输入功率：$P_1 = V_1 \times I_1 = 220 \times 0.22 = 48.4W$
   输出功率：$P_2 = V_2 \times I_2 = 22 \times 2.2 = 48.4W$
   输入=输出 ✓

5. **原边等效输入电阻**：
   $R_{in} = V_1 / I_1 = 220 / 0.22 = 1000Ω = 1kΩ$
   用公式验证：$R_{in} = (N1/N2)^2 \times R_L = 10^2 \times 10 = 1000Ω$ ✓

## 四、实际变压器的非理想特性

理想变压器不存在，实际变压器有各种非理想特性：

| 特性 | 说明 | 影响 |
|---|---|---|
| **铜损** | 线圈导线的电阻（DCR）产生的损耗 | 发热，降低效率，大电流时明显 |
| **铁损（铁芯损耗）** | 磁滞损耗 + 涡流损耗 | 发热，降低效率，高频时明显 |
| **漏感** | 部分磁通没有同时穿过原边和副边，漏到空气中 | 相当于串联电感，产生电压尖峰，影响高频响应 |
| **励磁电流** | 铁芯磁导率不是无穷大，需要电流产生磁通 | 原边有空载电流，增加损耗 |
| **饱和** | 铁芯磁通达到饱和，电感值急剧下降 | 原边电流急剧增大，过热损坏，产生失真 |
| **绕组电容** | 线圈匝间和层间的寄生电容 | 影响高频响应，有自谐振频率 |
| **效率** | 输出功率/输入功率 | 电力变压器效率95-99%，小信号变压器80-95% |

### 变压器的"嗡嗡"声是怎么来的

你听到的变压器"嗡嗡"声来自两个原因：
1. **磁致伸缩**：铁磁材料在磁场中会微小地伸缩，随交流磁场频率振动，产生声波
2. **机械振动**：铁芯叠片如果没有压紧，会在磁场力作用下振动发声

工频变压器的嗡嗡声是100Hz（因为磁场每周期变化两次，振动频率是电源频率的2倍）。

### 变压器为什么不能通直流

变压器的工作原理是**变化的电流产生变化的磁场，变化的磁场感应出电压**。直流电的电流不变，产生的磁场也不变，所以副边不会感应出电压——能量无法传递到副边。

更危险的是：直流下线圈的感抗为零，只有线圈电阻（通常很小），如果直接加直流电压，电流会非常大，导致线圈过热烧毁。所以变压器只能用于交流（或变化的电流，如PWM开关信号）。

## 五、变压器的常见应用

| 应用 | 场景 | 说明 |
|---|---|---|
| **电力变压器** | 电网输电 | 升压减少输电损耗，降压到民用电压 |
| **电源变压器** | 线性电源 | 把220V降到低压，再整流滤波 |
| **开关电源变压器** | 开关电源 | 高频变压器，体积小，效率高 |
| **脉冲变压器** | 数字电路/驱动 | 传递脉冲信号，隔离，阻抗变换 |
| **音频变压器** | 音频功放/话筒 | 阻抗匹配，隔离，平衡-不平衡转换 |
| **射频变压器** | 射频电路 | 阻抗匹配，平衡-不平衡转换（巴伦） |
| **隔离变压器** | 安全/测量 | 电气隔离，1:1匝数比，切断地环路 |
| **互感器** | 电力测量 | 电流互感器（CT）/电压互感器（PT），把大电流/高电压变成可测量的小信号 |
| **自耦变压器** | 可调电源 | 单线圈带抽头，体积小，无隔离 |

## 六、常见误区与坑

| 误区 | 正确理解 |
|---|---|
| "变压器能改变直流电压" | 变压器只能改变交流（或变化的）电压，直流不能通过变压器传递能量，还可能烧坏线圈 |
| "变压器的变压比和电流比都是N1:N2" | 变压比是N1:N2，变流比是N2:N1（反比），别搞混 |
| "理想变压器的原边等效电阻是N1/N2 × RL" | 是匝数比的**平方**：Rin = (N1/N2)² × RL，不是一次方 |
| "磁路和电路完全一样，直接套用就行" | 类比关系成立，但铁磁材料有非线性（饱和、磁滞），磁导率不是常数，这是和电路最大的不同 |
| "变压器的嗡嗡声是电流的声音" | 是铁芯磁致伸缩和机械振动产生的声波，频率是电源频率的2倍 |
| "变压器越大效率越高" | 不一定。大变压器铜损小但铁损大，小变压器铜损大但铁损小，最优效率在铜损=铁损时 |
| "漏感是有害的，越小越好" | 漏感确实会产生电压尖峰，但在某些电路（如LLC谐振变换器）中，漏感是谐振元件的一部分，是有用的 |
| "变压器饱和只是输出变小，没什么危险" | 饱和后原边电流急剧增大，会导致过热烧毁，还会产生严重的波形失真和EMI |

## 小结

这篇文章我们深入学习了磁路与变压器：

1. **电磁感应**：法拉第定律$v=N(d\Phi/dt)$，变化的磁场产生电压；楞次定律决定感应方向；自感和互感是电感和变压器的基础
2. **磁路-电路类比**：磁通↔电流，磁动势↔电压，磁阻↔电阻，磁导率↔电导率；磁路的"欧姆定律"$\Phi=F/\mathcal{R}$；电路分析方法可直接套用
3. **铁磁材料**：有磁化曲线、饱和、磁滞，磁导率不是常数；硅钢片/铁氧体/坡莫合金/非晶各有适用场景
4. **理想变压器**：变压比$V1/V2=N1/N2$，变流比$I1/I2=N2/N1$，阻抗变换$Rin=(N1/N2)^2×RL$；功率守恒
5. **实际变压器**：有铜损、铁损、漏感、励磁电流、饱和、绕组电容等非理想特性；效率通常80-99%
6. **常见应用**：电力变压器、电源变压器、开关电源变压器、脉冲变压器、音频/射频变压器、隔离变压器、互感器、自耦变压器

最重要的三句话：
- **变压器利用互感工作，只能传递交流（变化的）信号**——直流不能通过变压器，还可能烧坏线圈
- **磁路和电路有完美的类比关系**——学会了电路分析，磁路分析就很容易，只要记住铁磁材料有非线性（饱和）
- **变压器的三个变换：变压、变流、变阻抗**——记住变压比是匝数比，变流比是反比，阻抗变换是平方比
