## 开篇：为什么音频设备要标"频率响应 20Hz-20kHz"？

你买耳机、音箱、功放的时候，一定会看到一个参数："频率响应 20Hz-20kHz"。这个参数是什么意思？为什么是20Hz到20kHz？

答案是：这是一个电路（或设备）对不同频率信号的"响应"——也就是对不同频率信号的放大或衰减程度。20Hz-20kHz是人耳能听到的频率范围，所以音频设备要保证在这个范围内信号都能正常通过（不被过度衰减）。

描述电路对不同频率的响应，就是**频率响应**（Frequency Response）。而分析频率响应最常用的工具，就是**分贝**（dB）和**伯德图**（Bode Plot）。这篇文章我们就把这两个工具彻底讲透，还有滤波器设计的入门知识。

> 作者说："This chapter introduces two related items; the decibel and Bode plots. The decibel measurement scheme is in wide use, particularly in the fields of audio and communications... One of the more important parameters of a circuit is its frequency response, that is, the way in which the circuit responds to input signals over a range of frequencies."（第372页，10.1 Introduction）

## 一、分贝（dB）——用对数表示增益和衰减

### 1.1 为什么要用分贝

在音频和通信领域，信号的幅度变化范围非常大——从微伏级的微弱信号到伏级的强信号，幅度比可能是几百万倍。如果用线性坐标来表示，要么小信号看不清，要么大信号超出坐标范围。

分贝用**对数**来表示增益/衰减，把几百万倍的范围压缩到一个合理的数值范围。而且，多级系统的总增益是各级增益的乘积，用分贝表示后就变成了加法（因为对数把乘法变成加法），计算更方便。

### 1.2 分贝的定义

**功率增益**的分贝表示：

$$G_{dB} = 10 \log_{10}\left(\frac{P_{out}}{P_{in}}\right)$$

**电压增益**的分贝表示（阻抗相同时）：

$$G_{dB} = 20 \log_{10}\left(\frac{V_{out}}{V_{in}}\right)$$

注意：功率是10log，电压是20log。因为功率和电压的平方成正比（$P = V^2/R$），所以电压的分贝是功率分贝的2倍。

### 1.3 常用分贝值速查表

| 电压比 | 功率比 | 分贝值 | 说明 |
|---|---|---|---|
| 0.001 | 0.000001 | -60 dB | 衰减到千分之一 |
| 0.01 | 0.0001 | -40 dB | 衰减到百分之一 |
| 0.1 | 0.01 | -20 dB | 衰减到十分之一 |
| 0.707 | 0.5 | -3 dB | 半功率点（截止频率） |
| 1 | 1 | 0 dB | 无增益无衰减 |
| 1.414 | 2 | +3 dB | 功率翻倍 |
| 2 | 4 | +6 dB | 电压翻倍 |
| 10 | 100 | +20 dB | 电压放大10倍 |
| 100 | 10000 | +40 dB | 电压放大100倍 |
| 1000 | 1000000 | +60 dB | 电压放大1000倍 |

**记忆口诀**：电压×10 = +20dB，电压÷10 = -20dB；电压×2 = +6dB，电压÷2 = -6dB；半功率点 = -3dB。

### 1.4 生活类比

分贝就像地震的里氏震级——差1级，能量差32倍（约10^1.5）。里氏8级地震不是比7级大1/7，而是大32倍。分贝也是一样，+20dB不是大20%，而是大10倍。

## 二、伯德图——频率响应的可视化

### 2.1 什么是伯德图

伯德图（Bode Plot）是描述电路频率响应的两张图：
1. **幅频响应图**：增益（dB）随频率（对数坐标）的变化
2. **相频响应图**：相位（度）随频率（对数坐标）的变化

两张图的横轴都是频率的对数坐标（log scale），这样可以在一张图里展示很宽的频率范围（比如从1Hz到1MHz，6个数量级）。

> 作者说："A Bode plot is, in fact, a plot of a system's response with respect to frequency. Bode plots are of particular importance in the study of circuits such as amplifiers and filters, as well as in systems that make use of negative feedback."（第372页，10.1 Introduction）

### 2.2 伯德图的关键参数

| 参数 | 说明 |
|---|---|
| 截止频率（Corner/Break Frequency） | 增益开始下降的频率，RC电路中$f_c = 1/(2\pi RC)$ |
| 滚降斜率（Rolloff Slope） | 截止频率后增益下降的速度，一阶RC是-20dB/十倍频（-6dB/倍频程） |
| 通带增益（Passband Gain） | 截止频率前的增益（低通是低频段，高通是高频段） |
| 相位变化范围 | 一阶RC从0度到-90度（低通）或+90度（高通），截止频率处是-45度/+45度 |

### 2.3 怎么看伯德图

看伯德图三步走：
1. **看幅频图**：通带增益是多少？截止频率在哪？滚降斜率是多少？
2. **看相频图**：通带相位是多少？截止频率处相位是多少？高频/低频极限相位是多少？
3. **结合应用判断**：这个电路能通过什么频率范围的信号？对信号的相位有什么影响？

## 三、滞后网络和超前网络

### 3.1 滞后网络（Lag Network）= 低通滤波器

RC低通滤波器（电阻串联、电容并联、输出从电容取）就是一个滞后网络。

传递函数：

$$H(j\omega) = \frac{V_{out}}{V_{in}} = \frac{1}{1 + j\omega RC} = \frac{1}{1 + j(f/f_c)}$$

截止频率：

$$f_c = \frac{1}{2\pi RC}$$

伯德图特性：
- 幅频：低频段0dB（平坦），截止频率后以-20dB/十倍频滚降
- 相频：低频段0度，截止频率处-45度，高频段-90度
- 输出相位**滞后**于输入（所以叫滞后网络）

**生活类比**：低通滤波器就像一个"慢吞吞的人"——慢变化的信号（低频）他能跟上，快变化的信号（高频）他跟不上，就被过滤掉了。输出总是比输入慢半拍（相位滞后）。

### 3.2 超前网络（Lead Network）= 高通滤波器

RC高通滤波器（电容串联、电阻并联、输出从电阻取）就是一个超前网络。

传递函数：

$$H(j\omega) = \frac{V_{out}}{V_{in}} = \frac{j\omega RC}{1 + j\omega RC} = \frac{j(f/f_c)}{1 + j(f/f_c)}$$

截止频率：

$$f_c = \frac{1}{2\pi RC}$$

伯德图特性：
- 幅频：高频段0dB（平坦），截止频率前以+20dB/十倍频上升（即低频被衰减）
- 相频：高频段0度，截止频率处+45度，低频段+90度
- 输出相位**超前**于输入（所以叫超前网络）

**生活类比**：高通滤波器就像一个"急性子的人"——快变化的信号（高频）他反应很快，慢变化的信号（低频）他没反应，就被过滤掉了。输出总是比输入快半拍（相位超前）。

### 3.3 完整实例：RC低通滤波器设计

**题目**：设计一个RC低通滤波器，截止频率1kHz，通带增益0dB，输入阻抗不小于10kΩ。求R和C的值，并画出伯德图的关键参数。

**解**：

第一步：选R值（输入阻抗≈R，所以R≥10kΩ）

选$R = 10\text{k}\Omega$。

第二步：算C值

$$C = \frac{1}{2\pi f_c R} = \frac{1}{2\pi \times 1000 \times 10000} = \frac{1}{6.283\times10^7} = 15.9 \text{ nF}$$

选标准值$C = 16\text{ nF}$（或15nF，接近即可）。

第三步：伯德图关键参数

| 参数 | 值 |
|---|---|
| 截止频率$f_c$ | 1 kHz |
| 通带增益 | 0 dB（1倍） |
| 截止频率处增益 | -3 dB（0.707倍） |
| 滚降斜率 | -20 dB/十倍频（-6 dB/倍频程） |
| 10kHz处增益 | -3 + (-20) = -23 dB（约0.07倍） |
| 100Hz处增益 | ≈0 dB（远低于截止频率） |
| 截止频率处相位 | -45度 |
| 高频极限相位 | -90度 |

**验证**：用信号发生器输入1V正弦波，频率从100Hz扫到10kHz，用示波器测输出电压。100Hz时输出≈1V（0dB），1kHz时输出≈0.707V（-3dB），10kHz时输出≈0.07V（-23dB）。和理论值一致。

## 四、多级系统的伯德图——级联

### 4.1 级联的规则

当多个网络级联时（前一级的输出接后一级的输入），总传递函数是各级传递函数的乘积：

$$H_{total}(j\omega) = H_1(j\omega) \times H_2(j\omega) \times ...$$

用分贝表示后，总增益是各级增益的和（因为对数把乘法变成加法）：

$$G_{total}(dB) = G_1(dB) + G_2(dB) + ...$$

总相位也是各级相位的和：

$$\theta_{total} = \theta_1 + \theta_2 + ...$$

### 4.2 两级RC低通的级联

两个相同的RC低通滤波器级联（中间加电压跟随器隔离，避免负载效应）：
- 截止频率：还是$f_c$（每级相同）
- 通带增益：0dB
- 滚降斜率：-20 + (-20) = -40 dB/十倍频（-12 dB/倍频程）
- 截止频率处增益：-3 + (-3) = -6 dB
- 截止频率处相位：-45 + (-45) = -90度
- 高频极限相位：-90 + (-90) = -180度

**关键洞察**：每增加一级RC，滚降斜率增加-20dB/十倍频，相位变化范围增加90度。这就是为什么高阶滤波器的截止特性更陡峭——但相位滞后也更大，可能导致系统不稳定（特别是反馈系统）。

> 作者说："Combine the effects of several lead and lag networks together in order to determine a system Bode plot."（第372页，学习目标）

## 五、滤波器设计入门

### 5.1 四种基本滤波器类型

| 类型 | 通过的频率 | 衰减的频率 | 典型应用 |
|---|---|---|---|
| 低通（LPF） | 低于$f_c$ | 高于$f_c$ | 电源滤波、抗混叠滤波、DAC输出滤波 |
| 高通（HPF） | 高于$f_c$ | 低于$f_c$ | 隔直、交流耦合、去除低频噪声 |
| 带通（BPF） | $f_1$到$f_2$之间 | 低于$f_1$和高于$f_2$ | 收音机选频、信号提取、噪声抑制 |
| 带阻（BSF/Notch） | 低于$f_1$和高于$f_2$ | $f_1$到$f_2$之间 | 去除特定频率干扰（如50Hz工频干扰） |

### 5.2 滤波器的关键参数

| 参数 | 说明 |
|---|---|
| 截止频率$f_c$ | 增益下降到-3dB的频率 |
| 通带波纹（Passband Ripple） | 通带内增益的波动（dB） |
| 阻带衰减（Stopband Attenuation） | 阻带内的最小衰减（dB） |
| 过渡带宽度（Transition Band） | 从通带到阻带的频率范围，越窄越陡峭 |
| 阶数（Order） | 滤波器的复杂度，阶数越高过渡带越窄但相位失真越大 |

### 5.3 常见滤波器类型对比

| 类型 | 通带波纹 | 阻带衰减 | 相位线性 | 适用场景 |
|---|---|---|---|---|
| 巴特沃斯（Butterworth） | 无（最平坦） | 一般 | 一般 | 通用滤波，对通带平坦度要求高 |
| 切比雪夫I型（Chebyshev I） | 有波纹 | 好（同阶数衰减更大） | 差 | 对阻带衰减要求高，允许通带波纹 |
| 切比雪夫II型（Chebyshev II） | 无 | 有波纹 | 一般 | 通带平坦，阻带有波纹 |
| 贝塞尔（Bessel） | 无 | 一般 | 最好（线性相位） | 对相位失真要求高（如脉冲信号滤波） |
| 椭圆（Elliptic） | 有波纹 | 最好（同阶数衰减最大） | 差 | 对阻带衰减要求极高，允许通带和阻带都有波纹 |

**设计建议**：
- 入门先用巴特沃斯（最简单，通带最平坦）
- 需要更陡峭的截止特性时，增加阶数或用切比雪夫
- 处理脉冲信号或对相位敏感的信号时，用贝塞尔
- 实际设计用工具（如TI的FilterPro、ADI的Filter Wizard）自动计算元件值

## 六、常见误区和坑

| 误区 | 正确理解 |
|---|---|
| 分贝是线性单位 | 分贝是对数单位，+20dB是10倍不是20% |
| 功率增益和电压增益的分贝公式一样 | 功率是10log，电压是20log（因为P∝V²） |
| 截止频率是增益为0的频率 | 截止频率是增益下降到-3dB（0.707倍）的频率，不是0 |
| 两级RC直接级联就行 | 直接级联有负载效应（后一级的输入阻抗影响前一级），需要加缓冲器 |
| 滤波器阶数越高越好 | 阶数越高截止越陡峭，但相位失真越大、元件越多、成本越高 |
| 伯德图的横轴是线性坐标 | 伯德图的横轴是对数坐标（log scale），每格是10倍频 |
| 低通滤波器的输出相位超前 | 低通是滞后网络，输出相位滞后于输入（0到-90度） |
| 所有滤波器都用巴特沃斯 | 不同应用选不同类型，相位敏感用贝塞尔，阻带衰减要求高用切比雪夫/椭圆 |

## 小结

这篇文章我们深入拆解了电路频率响应的分析工具：

1. **分贝（dB）**：用对数表示增益/衰减，把宽范围压缩到合理数值。功率增益用10log，电压增益用20log。常用值：×10=+20dB，×2=+6dB，半功率=-3dB。
2. **伯德图**：频率响应的可视化，两张图——幅频图（增益dB vs 频率log）和相频图（相位 vs 频率log）。关键参数：截止频率、滚降斜率、通带增益、相位变化。
3. **滞后/超前网络**：RC低通=滞后网络（输出相位滞后0到-90度，-20dB/十倍频滚降），RC高通=超前网络（输出相位超前+90到0度）。截止频率都是$f_c = 1/(2\pi RC)$。
4. **多级级联**：总增益=各级增益之和（dB），总相位=各级相位之和。每增加一级RC，滚降斜率增加-20dB/十倍频，相位范围增加90度。
5. **滤波器设计入门**：四种基本类型（低通/高通/带通/带阻），关键参数（截止频率/通带波纹/阻带衰减/过渡带/阶数），五种常见滤波器对比（巴特沃斯/切比雪夫/贝塞尔/椭圆）。

频率响应是模拟电路设计的核心。理解了分贝和伯德图，你就能分析放大器的带宽、滤波器的特性、系统的稳定性，也能看懂datasheet里的频率响应曲线。
