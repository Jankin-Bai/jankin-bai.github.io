## 开篇：收音机怎么从几百个电台里选出你想听的那个？

你转动收音机的调台旋钮，"唰"的一下，从一个电台跳到另一个电台。空气中同时存在着几百个电台的信号，每个电台用不同的频率广播。收音机是怎么做到"只听一个台，其他台都静音"的？

答案就是**谐振**。一个LC谐振电路就像一个"频率筛子"——只让特定频率的信号通过，其他频率的信号都被挡住。转动调台旋钮，其实就是在改变电容的容量，从而改变谐振频率，选出不同的电台。

谐振是AC电路里最"神奇"也最有用的现象。这篇文章我们就把谐振彻底讲透：串联谐振、并联谐振、品质因数Q、带宽、选频电路设计，还有实际电感的非理想性对谐振电路的影响。

> 作者说："Resonance can be thought of as a preferred frequency of vibration. In other words, it is a frequency at which a system operates with reduced limitation. It is exploited in a variety of areas, for example, a good mechanical resonance can be used for the construction of acoustic musical instruments."（第294页，8.1 Introduction）

## 一、串联谐振——阻抗最小，电流最大

### 1.1 什么是串联谐振

串联RLC电路中，总阻抗是：

$$Z = R + j(X_L - X_C) = R + j\left(\omega L - \frac{1}{\omega C}\right)$$

当$\omega L = \frac{1}{\omega C}$时，虚部为0，阻抗最小（等于R），电流最大。这就是**串联谐振**。

谐振角频率和谐振频率：

$$\omega_0 = \frac{1}{\sqrt{LC}}, \quad f_0 = \frac{1}{2\pi\sqrt{LC}}$$

### 1.2 串联谐振的特性

| 特性 | 谐振时的值 | 说明 |
|---|---|---|
| 阻抗 | $Z = R$（最小） | 虚部为0，呈纯阻性 |
| 电流 | $I = V/R$（最大） | 阻抗最小所以电流最大 |
| 电感电压 | $V_L = I \times X_L = Q \times V$ | 可能远大于电源电压！ |
| 电容电压 | $V_C = I \times X_C = Q \times V$ | 和电感电压大小相等、相位相反 |
| 相位 | 0度 | 电压电流同相位 |

**关键洞察**：串联谐振时，电感电压和电容电压可能是电源电压的Q倍！比如Q=100，电源1V，电感和电容上的电压就是100V。这就是为什么串联谐振也叫**电压谐振**。

> 作者说："In the case of series resonance, the impedance reaches a minimum at the resonant frequency... at the resonance frequency of 159 kHz would be Q times greater, or 200"（第8章，约第305页）

### 1.3 生活类比

串联谐振就像荡秋千：
- 你推秋千的频率（电源频率）和秋千的固有频率（谐振频率）一致时，秋千越荡越高（电流越来越大）
- 秋千的最高点（电感/电容电压）可能比你推的高度（电源电压）高很多——这就是"电压放大"
- 如果推的频率不对，秋千就荡不起来（电流小）

## 二、并联谐振——阻抗最大，电流最小

### 2.1 什么是并联谐振

并联RLC电路中，总导纳是：

$$Y = \frac{1}{R} + j\left(\omega C - \frac{1}{\omega L}\right)$$

当$\omega C = \frac{1}{\omega L}$时，虚部为0，导纳最小（等于1/R），阻抗最大。这就是**并联谐振**。

谐振频率和串联谐振一样：$f_0 = \frac{1}{2\pi\sqrt{LC}}$（高Q时近似相等）。

### 2.2 并联谐振的特性

| 特性 | 谐振时的值 | 说明 |
|---|---|---|
| 阻抗 | $Z = R$（最大，理想情况） | 虚部为0，呈纯阻性 |
| 总电流 | $I = V/R$（最小） | 阻抗最大所以总电流最小 |
| 电感电流 | $I_L = V/X_L$ | 可能远大于总电流！ |
| 电容电流 | $I_C = V/X_C$ | 和电感电流大小相等、相位相反 |
| 相位 | 0度 | 电压电流同相位 |

**关键洞察**：并联谐振时，电感电流和电容电流可能是总电流的Q倍！比如Q=100，总电流1mA，电感和电容里的电流就是100mA。这就是为什么并联谐振也叫**电流谐振**。

并联谐振电路也叫**槽路**（Tank Circuit），因为能量在电感和电容之间来回振荡，就像水在水槽里来回晃。

> 作者说："parallel resonance produces an impedance peak at resonance. This implies a current minimum for a circuit driven by a voltage source."（第8章，约第295页）

### 2.3 生活类比

并联谐振就像两个小孩在跷跷板上：
- 一个小孩（电感）的能量和另一个小孩（电容）的能量来回交换
- 当交换频率等于固有频率（谐振频率）时，两个小孩荡得最欢（电感/电容电流最大）
- 但从外面看，跷跷板的支撑点（总电流）几乎不用使劲——因为两个小孩的力互相抵消了

## 三、品质因数Q和带宽

### 3.1 什么是品质因数Q

品质因数Q（Quality Factor）衡量谐振电路的"好坏"——Q越高，谐振峰越尖锐，选频能力越强。

串联谐振电路的Q：

$$Q = \frac{X_L}{R} = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

并联谐振电路的Q（高Q时）：

$$Q = \frac{R}{X_L} = \frac{R}{\omega_0 L} = R \omega_0 C = R \sqrt{\frac{C}{L}}$$

> 注意：串联Q和并联Q的公式不一样！串联是$X_L/R$，并联是$R/X_L$。不要搞混。

### 3.2 带宽和半功率点

谐振电路的**带宽**（Bandwidth，BW）是指谐振峰两侧，功率下降到最大值一半时的频率范围。

$$BW = \frac{f_0}{Q}$$

带宽越窄，选频能力越强（能更精确地选出某个频率）；带宽越宽，选频能力越弱，但能通过更宽的频率范围。

**半功率点**（Half-Power Points）：功率下降到最大值一半时的上下两个频率$f_1$和$f_2$。因为功率和电压的平方成正比，半功率对应电压下降到$1/\sqrt{2} \approx 0.707$倍（即-3dB）。

$$f_1 = f_0 - \frac{BW}{2}, \quad f_2 = f_0 + \frac{BW}{2} \quad \text{（高Q时近似）}$$

$$BW = f_2 - f_1$$

### 3.3 Q、带宽、选择性的关系

| Q值 | 谐振峰 | 带宽 | 选频能力 | 典型应用 |
|---|---|---|---|---|
| 高Q（>100） | 尖锐 | 窄 | 强 | 收音机选频、射频滤波器、振荡器 |
| 中Q（10-100） | 较尖锐 | 中等 | 中等 | 音频滤波器、阻抗匹配 |
| 低Q（<10） | 平缓 | 宽 | 弱 | 电源滤波、阻尼电路、宽带放大器 |

**对无线电爱好者的意义**：你做的SDR接收机，前端选频电路的Q值决定了接收的选择性——Q太低，邻道干扰大；Q太高，带宽太窄，可能通不过信号带宽（比如FM广播需要200kHz带宽）。实际设计中要在选择性和带宽之间找平衡。

## 四、谐振选频电路设计实例

### 4.1 题目

设计一个串联谐振选频电路，用于接收1MHz的调幅广播信号。要求：
- 谐振频率$f_0 = 1$ MHz
- 品质因数$Q = 50$
- 源内阻$R_s = 50\Omega$
- 用一个电感和一个电容串联，电阻是电感的串联电阻+源内阻

求：电感值L、电容值C、总电阻R、带宽BW、上下半功率点频率。

### 4.2 解

第一步：选电感值（通常先选L，再算C）

假设选$L = 10\mu H$（常用值）。

第二步：算电容值

$$C = \frac{1}{(2\pi f_0)^2 L} = \frac{1}{(2\pi \times 10^6)^2 \times 10\times10^{-6}} = \frac{1}{3.948\times10^{14} \times 10^{-5}} = \frac{1}{3.948\times10^9} = 253 \text{ pF}$$

第三步：算总电阻（由Q值决定）

$$Q = \frac{\omega_0 L}{R} \implies R = \frac{\omega_0 L}{Q} = \frac{2\pi \times 10^6 \times 10\times10^{-6}}{50} = \frac{62.83}{50} = 1.26 \Omega$$

注意：这个R是总电阻，包括源内阻50Ω和电感的串联电阻。但源内阻已经50Ω了，远大于1.26Ω，说明这个设计有问题——源内阻太大，Q值上不去。

**修正**：实际设计中，如果源内阻太大，应该用并联谐振电路（源内阻并联在槽路上，Q = R/X_L，R越大Q越高），或者用阻抗匹配网络把源内阻变换到合适的值。

让我们改用并联谐振电路：

$$Q = \frac{R}{\omega_0 L} \implies L = \frac{R}{Q \omega_0} = \frac{50}{50 \times 2\pi \times 10^6} = \frac{50}{3.14\times10^8} = 0.159 \mu H$$

这个电感值太小了，不太实际。实际中通常用变压器或电容分压来做阻抗匹配，或者用更高Q的电感。

**这个例子说明**：谐振电路设计不是简单套公式，还要考虑源内阻、负载电阻、实际元件值等因素。这就是为什么实际射频电路设计需要经验和反复调试。

### 4.3 带宽和半功率点

假设Q=50，f0=1MHz：

$$BW = \frac{f_0}{Q} = \frac{10^6}{50} = 20 \text{ kHz}$$

$$f_1 = f_0 - \frac{BW}{2} = 1000 - 10 = 990 \text{ kHz}$$

$$f_2 = f_0 + \frac{BW}{2} = 1000 + 10 = 1010 \text{ kHz}$$

调幅广播的频道间隔是10kHz，带宽20kHz意味着会收到相邻频道的信号——Q=50可能不够，需要更高的Q（比如Q=100，带宽10kHz）。

## 五、实际电感的非理想性对谐振的影响

> 作者在第8章专门讲了实际电感的Q值："Q, or quality factor, of an inductor... at the resonance frequency of 159 kHz would be Q times greater"（第8章，约第310页）

理想电感没有电阻，但实际电感有：
1. **串联电阻（DCR）**：导线的直流电阻，降低Q值
2. **磁芯损耗**：磁芯材料的涡流和磁滞损耗，等效为并联电阻，高频时明显
3. **寄生电容**：线圈匝间的电容，和电感并联，形成自谐振频率（SRF）

这些非理想因素导致：
- 实际Q值比理论值低（因为有额外的电阻损耗）
- 谐振频率偏移（因为寄生电容和电感并联，总电容变大）
- 超过自谐振频率后，电感变成容性（寄生电容占主导）

**设计要点**：
- 选电感时看datasheet的Q值曲线和自谐振频率（SRF）
- 工作频率要远低于SRF（通常<1/3 SRF）
- 高频时选空心电感或高Q磁芯（如铁氧体NiZn材质）
- 谐振电路的实际Q值 = 电感Q值和电路Q值的并联（取较小的那个）

## 六、常见误区和坑

| 误区 | 正确理解 |
|---|---|
| 串联谐振和并联谐振的Q公式一样 | 串联Q=X_L/R，并联Q=R/X_L，不一样 |
| 谐振时电感/电容电压等于电源电压 | 串联谐振时是电源电压的Q倍，可能远大于电源电压 |
| 谐振时电感/电容电流等于总电流 | 并联谐振时是总电流的Q倍，可能远大于总电流 |
| Q越高越好 | Q高选择性好但带宽窄，要根据信号带宽选择合适的Q |
| 实际电感的Q值是常数 | Q值随频率变化，datasheet里有Q值曲线 |
| 谐振频率只和L、C有关 | 实际电路中还有寄生电容、源内阻、负载电阻的影响 |
| 带宽=f0/Q只适用于所有情况 | 只适用于高Q（Q>10）情况，低Q时谐振峰不对称，公式不精确 |
| 串联谐振时阻抗为0 | 理想情况（R=0）阻抗为0，实际有电阻，阻抗=R |

## 小结

这篇文章我们深入拆解了谐振的核心原理：

1. **串联谐振**：$\omega L = 1/(\omega C)$时，阻抗最小（=R），电流最大，电感/电容电压是电源电压的Q倍（电压谐振）。谐振频率$f_0 = 1/(2\pi\sqrt{LC})$。
2. **并联谐振**：$\omega C = 1/(\omega L)$时，阻抗最大，总电流最小，电感/电容电流是总电流的Q倍（电流谐振）。也叫槽路，能量在L和C之间来回振荡。
3. **品质因数Q和带宽**：Q衡量谐振峰的尖锐程度，$BW = f_0/Q$。Q越高选择性越好但带宽越窄，要根据应用选择合适的Q。
4. **选频电路设计**：谐振电路是收音机选频、射频滤波器、振荡器的核心。设计时要考虑源内阻、负载电阻、实际元件Q值等因素，不是简单套公式。
5. **实际电感的非理想性**：实际电感有串联电阻、磁芯损耗、寄生电容，会降低Q值、偏移谐振频率。选电感时要看Q值曲线和自谐振频率。

谐振是无线电/射频电路的灵魂。理解了谐振，你就能理解收音机怎么选台、滤波器怎么选频、振荡器怎么产生稳定的频率信号。
